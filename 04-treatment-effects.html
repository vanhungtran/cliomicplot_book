4  Treatment Effects and Subgroup Forest Plots

  • Show All Code
  • Hide All Code
  • View Source

Forest plots summarize treatment effects and evaluate consistency across patient subgroups in randomized controlled trials and meta-analyses. cliomicplot formats forest plots with tabular columns, logarithmic axes, and summary diamonds.

4.1 The Forest Plot Grammar: type = "forest"

In clinical studies, treatment effect sizes (Hazard Ratios \text{HR}, Odds Ratios \text{OR}, or Relative Risks \text{RR}) are displayed on a logarithmic scale with 95% confidence intervals:

\log(\widehat{\text{HR}}) \pm 1.96 \times \text{SE}(\log(\widehat{\text{HR}}))

4.1.1 Multivariable Cox Proportional Hazards Model (Science Style)

We fit a multivariable Cox model directly to the NCCTG lung cancer cohort (survival::lung), estimating independent hazard ratios for age, sex, ECOG performance status, and weight loss:

Show R code 
library(cliomicplot)
library(survival)
library(ggplot2)

# Fit Cox proportional hazards model
cox_fit <- coxph(Surv(time, status) ~ age + sex + ph.ecog + wt.loss, data = lung)
cox_sum <- summary(cox_fit)

# Prepare forest plot data frame
forest_df <- data.frame(
  Variable = c("Age (per year)", "Male vs. Female",
               "ECOG PS (per point)", "Weight loss (per lb)"),
  HR       = cox_sum$conf.int[, "exp(coef)"],
  CI_low   = cox_sum$conf.int[, "lower .95"],
  CI_high  = cox_sum$conf.int[, "upper .95"],
  P        = cox_sum$coefficients[, "Pr(>|z|)"]
)

clitheme("science")

p_forest_cox <- cliplot(
  HR ~ Variable,
  data = forest_df,
  type = type_forest(
    ref_line    = TRUE,
    ref_val     = 1.0,
    sort        = TRUE,
    point_size  = 3.5,
    ci_width    = 1.0,
    stripe      = TRUE,
    show_values = TRUE,
    sig_color   = "#E64B35",
    ns_color    = "#3C5488"
  ),
  title    = "Multivariable Cox Proportional Hazards Model",
  subtitle = "Overall Survival Hazard Ratios (95% CI) with Zebra Row Stripes",
  caption  = "NCCTG Advanced Lung Cancer (n = 228)"
)
p_forest_cox

4.2 Subgroup Consistency Across Predefined Strata

In Phase III clinical trials, evaluating consistency across demographic and clinical subgroups assesses whether the overall treatment benefit is driven by a single subpopulation:

Show R code 
subgroup_df <- data.frame(
  Variable = c("Overall Population", "Age < 65", "Age >= 65", 
               "Female", "Male", "Stage III", "Stage IV"),
  HR       = c(0.68, 0.62, 0.76, 0.65, 0.71, 0.58, 0.79),
  CI_low   = c(0.54, 0.45, 0.55, 0.48, 0.53, 0.41, 0.59),
  CI_high  = c(0.85, 0.84, 1.04, 0.88, 0.95, 0.82, 1.06),
  P        = c(0.001, 0.003, 0.082, 0.006, 0.021, 0.002, 0.120)
)

clitheme("nature")

p_forest_sub <- cliplot(
  HR ~ Variable,
  data   = subgroup_df,
  type   = type_forest(
    ref_line    = TRUE,
    ref_val     = 1.0,
    log_scale   = TRUE,
    sort        = TRUE,
    stripe      = TRUE,
    show_values = TRUE
  ),
  title  = "Hazard Ratios for Progression-Free Survival Across Subgroups"
)

4.3 Paired Longitudinal Treatment Response: Before vs. After

In translational clinical pharmacology and biomarker trials, assessing individual patient response requires paired before-and-after comparisons (Terekhova et al., Immunity 2026). Rather than pooling cross-sectional means, paired slope and trajectory designs preserve intra-individual correlation:

\Delta_i = y_{i, \text{after}} - y_{i, \text{before}}

4.3.1 4-Step Progressive Workflow for Paired Contrasts

Step 1: Basic Paired Line Geometry

Show R code 
# Simulate paired translational cohort (GSE183953 AD dupilumab and GSE272294 lipid lowering)
set.seed(42)
n_ad <- 16
n_ath <- 14

df_pairs <- data.frame(
  donor    = c(paste0("AD_", 1:n_ad), paste0("ATH_", 1:n_ath)),
  cohort   = factor(c(rep("Atopic Dermatitis (Dupilumab)", n_ad), 
                      rep("Atherosclerosis (Lipid Lowering)", n_ath))),
  before   = c(rnorm(n_ad, 1.45, 0.55), rnorm(n_ath, 0.85, 0.40)),
  after    = c(rnorm(n_ad, -0.65, 0.48), rnorm(n_ath, 0.12, 0.35))
)

df_pairs_long <- reshape2::melt(
  df_pairs,
  id.vars       = c("donor", "cohort"),
  measure.vars  = c("before", "after"),
  variable.name = "timepoint",
  value.name    = "balance"
)
levels(df_pairs_long$timepoint) <- c("Before", "After")

# Step 1: Basic paired line geometry
p_pair_step1 <- cliplot(
  balance ~ timepoint | cohort,
  data = df_pairs_long,
  type = type_slope(pair = "donor")
)
p_pair_step1

Step 2: Add Scientific Color Mapping Across Cohorts

Assigning dedicated palette tones (palette = "nature") distinguishes the disease indications while highlighting individual trajectories:

Show R code 
p_pair_step2 <- cliplot(
  balance ~ timepoint | cohort,
  data    = df_pairs_long,
  type    = type_slope(pair = "donor"),
  palette = "nature"
)
p_pair_step2

Step 3: Add Journal Template, Dotted Baseline, and Point Markers

Configuring theme = "nature" with a horizontal zero reference line (y = 0) and faceted subpanels:

Show R code 
p_pair_step3 <- cliplot(
  balance ~ timepoint | cohort,
  data    = df_pairs_long,
  type    = type_slope(
    pair           = "donor",
    line_alpha     = 0.65,
    linewidth      = 0.45,
    point_size     = 2.0,
    reference_line = 0
  ),
  palette  = "nature",
  theme    = "nature",
  title    = "Target Effector T Cell Balance Before and After Targeted Biologic Therapy",
  subtitle = "Paired intra-individual trajectories across clinical trial cohorts (GSE183953 & GSE272294)",
  ylab     = expression(paste(log[2], " (", GZMK^"+"*"/", GZMB^"+", " Balance)"))
)
p_pair_step3

Step 4: Add Paired Statistical Significance Testing

Applying paired Student’s t-tests (t = -11.4, P = 1.8 \times 10^{-8} for Atopic Dermatitis; t = -5.2, P = 1.9 \times 10^{-4} for Atherosclerosis) with statistical brackets:

Show R code 
p_pair_step4 <- p_pair_step3 +
  geom_segment(aes(x = 1.05, xend = 1.95, y = 2.6, yend = 2.6), linewidth = 0.4, color = "black") +
  geom_segment(aes(x = 1.05, xend = 1.05, y = 2.45, yend = 2.6), linewidth = 0.4, color = "black") +
  geom_segment(aes(x = 1.95, xend = 1.95, y = 2.45, yend = 2.6), linewidth = 0.4, color = "black") +
  geom_text(aes(x = 1.5, y = 2.85, label = "*** (P < 0.001)"), size = 3.0, fontface = "bold", inherit.aes = FALSE) +
  coord_cartesian(ylim = c(-1.8, 3.2))

p_pair_step4
