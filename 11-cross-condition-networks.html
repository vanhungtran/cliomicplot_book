11  Cross-Condition Network Module Comparison and Trait Association

  • Show All Code
  • Hide All Code
  • View Source

Comparing biological co-occurrence networks between healthy and diseased states requires evaluating whether functional modules share feature composition and covary with clinical phenotypes. cliomicplot calculates hypergeometric overlap and Representation Factors (RF) through type_module_compare(), and maps module-trait associations through type_module_trait().

11.1 Mathematical Formulation of Module Overlap

Given a background universe of N total features, module M_1 from Condition 1 containing |M_1| features, and module M_2 from Condition 2 containing |M_2| features, the overlap count is k = |M_1 \cap M_2|.

11.1.1 Jaccard Similarity Index

J(M_1, M_2) = \frac{|M_1 \cap M_2|}{|M_1 \cup M_2|} = \frac{k}{|M_1| + |M_2| - k}

11.1.2 Representation Factor (RF)

The Representation Factor quantifies whether the observed overlap exceeds what is expected by chance (RF > 1.0 indicates enrichment, RF < 1.0 indicates depletion):

RF = \frac{|M_1 \cap M_2|}{\mathbb{E}[|M_1 \cap M_2|]} = \frac{k}{\frac{|M_1| \cdot |M_2|}{N}} = \frac{k \cdot N}{|M_1| \cdot |M_2|}

11.1.3 Hypergeometric Overlap Significance

P(X \ge k) = \sum_{x=k}^{\min(|M_1|, |M_2|)} \frac{\binom{|M_2|}{x} \binom{N - |M_2|}{|M_1| - x}}{\binom{N}{|M_1|}}

11.2 Cross-Network Module Overlap: type = "module_compare"

Show R code 
library(cliomicplot)

set.seed(42)
taxa_pool <- paste0("Taxon_", 1:150)
net_discovery <- sample(c("M1_StaphCommensal", "M2_Lipophilic", "M3_Coryneform", "M4_PathogenCluster"), 150, replace = TRUE)
net_replication <- net_discovery

# Reorganize 35% of taxa to simulate biological perturbation
perm_idx <- sample(1:150, 50)
net_replication[perm_idx] <- sample(c("ModA_Commensal", "ModB_LipidUtil", "ModC_Actinobacteria", "ModD_Inflammation"), 50, replace = TRUE)
net_replication[-perm_idx] <- gsub("M1_StaphCommensal", "ModA_Commensal", net_replication[-perm_idx])
net_replication[-perm_idx] <- gsub("M2_Lipophilic", "ModB_LipidUtil", net_replication[-perm_idx])
net_replication[-perm_idx] <- gsub("M3_Coryneform", "ModC_Actinobacteria", net_replication[-perm_idx])
net_replication[-perm_idx] <- gsub("M4_PathogenCluster", "ModD_Inflammation", net_replication[-perm_idx])

network_df <- data.frame(
  Taxon       = taxa_pool,
  Discovery   = net_discovery,
  Replication = net_replication,
  stringsAsFactors = FALSE
)

p_comp <- cliplot(
  Replication ~ Discovery,
  data = network_df,
  type = type_module_compare(
    fill_by     = "rf",
    show_stars  = TRUE,
    show_totals = TRUE
  ),
  preset = "nature",
  title  = "Cross-Network Module Preservation: Discovery vs Replication Cohorts",
  xlab   = "Discovery Cohort Modules",
  ylab   = "Replication Cohort Modules"
)
p_comp

# Cross-Condition Network Module Comparison and Trait Association

Comparing biological co-occurrence networks between healthy and diseased states requires evaluating whether functional modules share feature composition and covary with clinical phenotypes. `cliomicplot` calculates hypergeometric overlap and Representation Factors ($RF$) through `type_module_compare()`, and maps module-trait associations through `type_module_trait()`.

## Mathematical Formulation of Module Overlap

Given a background universe of $N$ total features, module $M_1$ from Condition 1 containing $|M_1|$ features, and module $M_2$ from Condition 2 containing $|M_2|$ features, the overlap count is $k = |M_1 \cap M_2|$.

### Jaccard Similarity Index

$$J(M_1, M_2) = \frac{|M_1 \cap M_2|}{|M_1 \cup M_2|} = \frac{k}{|M_1| + |M_2| - k}$$

### Representation Factor ($RF$)

The Representation Factor quantifies whether the observed overlap exceeds what is expected by chance ($RF > 1.0$ indicates enrichment, $RF < 1.0$ indicates depletion):

$$RF = \frac{|M_1 \cap M_2|}{\mathbb{E}[|M_1 \cap M_2|]} = \frac{k}{\frac{|M_1| \cdot |M_2|}{N}} = \frac{k \cdot N}{|M_1| \cdot |M_2|}$$

### Hypergeometric Overlap Significance

$$P(X \ge k) = \sum_{x=k}^{\min(|M_1|, |M_2|)} \frac{\binom{|M_2|}{x} \binom{N - |M_2|}{|M_1| - x}}{\binom{N}{|M_1|}}$$
