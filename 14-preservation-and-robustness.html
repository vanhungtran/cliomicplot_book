Assessing biological network changes between health and disease requires testing whether module structures persist and whether the network withstands random loss or targeted hub disruption.

14.1 Module Preservation Statistics (Z_{\text{summary}})

cli_module_preservation() evaluates whether module density and intramodular hub rank are preserved between reference and test conditions under permutation testing (Langfelder et al., PLoS Comput Biol 2011).

14.1.1 Mathematical Definition of Z_{\text{summary}}

The composite preservation statistic Z_{\text{summary}} aggregates density and connectivity preservation metrics over B permutations:

Z_{\text{summary}} = \frac{Z_{\text{density}} + Z_{\text{connectivity}}}{2}

where Z_{\text{density}} evaluates whether features within module q maintain elevated mutual correlation and clustering in the test condition:

Z_{\text{density}} = \frac{Z_{\text{mean\_adj}} + Z_{\text{mean\_k}} + Z_{\text{cluster\_coef}} + Z_{\text{density\_raw}}}{4}

and Z_{\text{connectivity}} evaluates whether intramodular hub feature rankings are conserved between reference and test networks:

Z_{\text{connectivity}} = \frac{Z_{\text{kIM}} + Z_{\text{kME}}}{2}, \quad Z = \frac{\text{obs} - \mu_{\text{perm}}}{\sigma_{\text{perm}}}

  • Preservation Thresholds:
    • Z < 2 (dashed red line): No statistical evidence of module preservation.
    • 2 \le Z \le 10 (dashed orange line): Moderate module preservation.
    • Z > 10 (dashed green line): Strong, statistically significant module preservation.
Show R code 
library(cliomicplot)

demo_omics <- cli_demo_vitality_multiomics(n_samples = 35, n_features = 60, seed = 42)

pres_stats <- cli_module_preservation(
  ref_data    = demo_omics$ref_expr,
  test_data   = demo_omics$test_expr,
  ref_modules = demo_omics$modules,
  n_perm      = 100,
  seed        = 42
)

cliplot_module_preservation(
  pres_stats,
  title = "Cross-Network Module Preservation: WT Reference vs KO Test"
)

14.2 Network Robustness and Targeted Attack Simulation

cli_network_robustness() simulates progressive network degradation under random node loss versus targeted attacks on high-degree hub nodes. cliplot_network_robustness() displays natural connectivity decay curves.

14.2.1 Mathematical Formulation of Natural Connectivity

Natural connectivity \bar{\lambda} derives from the spectrum of the network adjacency matrix A and reflects the redundancy of alternative paths between all node pairs (Wu et al., IEEE Trans Reliab 2012):

\bar{\lambda} = \ln \left( \frac{1}{N} \sum_{i=1}^N e^{\lambda_i} \right)

where \lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_N are the eigenvalues of A. Natural connectivity strictly decreases monotonically as edges and nodes are removed, quantifying alternate path redundancy and topological stability.

The competitive-to-cooperative edge balance is evaluated as:

R_{\pm} = \frac{E_{-}}{E_{+}}

Show R code 
rob_stats <- cli_network_robustness(
  networks     = demo_omics$networks,
  attack       = c("random", "degree"),
  rm_fractions = seq(0.05, 0.85, by = 0.05),
  n_perm       = 20,
  metric       = "natural_connectivity",
  seed         = 42
)

cliplot_network_robustness(
  rob_stats,
  title = "Network Robustness Under Progressive Node Removal"
)

14.3 Zi-Pi Keystone Ecological Role Plot: type = "zipi"

Keystone taxa play disproportionately vital roles in maintaining community structure. The Zi-Pi classification framework (Guimerà & Amaral, Nature 2005; Deng et al., Science 2012; Tao Wen et al., iMeta 2025) maps within-module connectivity z-score (Z_i) against among-module participation coefficient (P_i):

  • Within-module connectivity (Z_i): Z_i = \frac{k_{i, s_i} - \bar{k}_{s_i}}{\sigma_{k_{s_i}}} where k_{i, s_i} is the degree of node i inside its own module s_i, \bar{k}_{s_i} is the mean intra-module degree, and \sigma_{k_{s_i}} is the standard deviation.

  • Participation coefficient (P_i): P_i = 1 - \sum_{s=1}^{N_M} \left( \frac{k_{i, s}}{k_i} \right)^2 where k_{i, s} is the number of links from node i to module s, and k_i is the total degree of node i.

Standard cutoffs (Z = 2.5, P = 0.62) partition the plane into four topological roles: 1. Peripherals (Z_i \le 2.5, P_i \le 0.62): Module specialists with few inter-module links. 2. Connectors (Z_i \le 2.5, P_i > 0.62): Generalists linking distinct modules. 3. Module hubs (Z_i > 2.5, P_i \le 0.62): Highly connected specialists inside their module. 4. Network hubs (Z_i > 2.5, P_i > 0.62): Super-generalists critical to global network integrity.

type_zipi() automates role classification, renders soft shaded background quadrants, adds marginal density rugs, and labels keystone taxa with collision-free text:

Show R code 
set.seed(42)
n_taxa <- 45
zipi_df <- data.frame(
  taxa   = paste0("ASV_", sprintf("%02d", seq_len(n_taxa))),
  Zi     = c(rnorm(38, mean = -0.2, sd = 0.9), rnorm(4, mean = 2.9, sd = 0.3), rnorm(3, mean = 2.8, sd = 0.4)),
  Pi     = c(runif(35, 0.05, 0.55), runif(4, 0.65, 0.85), runif(3, 0.15, 0.45), runif(3, 0.68, 0.92)),
  Phylum = sample(c("Bacteroidetes", "Firmicutes", "Actinobacteria", "Proteobacteria"), n_taxa, replace = TRUE),
  stringsAsFactors = FALSE
)

p_zipi <- cliplot(
  Zi ~ Pi,
  data  = zipi_df,
  type  = type_zipi(point_size = 3.2, label_top = 6),
  title = "Microbial Keystone Hub Identification (Zi-Pi Role Classification)"
)
p_zipi

# Module Preservation and Targeted Attack Robustness

Assessing biological network changes between health and disease requires testing whether module structures persist and whether the network withstands random loss or targeted hub disruption.

## Module Preservation Statistics ($Z_{\text{summary}}$)

`cli_module_preservation()` evaluates whether module density and intramodular hub rank are preserved between reference and test conditions under permutation testing (Langfelder et al., *PLoS Comput Biol* 2011).

### Mathematical Definition of $Z_{\text{summary}}$

The composite preservation statistic $Z_{\text{summary}}$ aggregates density and connectivity preservation metrics over $B$ permutations:

$$Z_{\text{summary}} = \frac{Z_{\text{density}} + Z_{\text{connectivity}}}{2}$$

where $Z_{\text{density}}$ evaluates whether features within module $q$ maintain elevated mutual correlation and clustering in the test condition:

$$Z_{\text{density}} = \frac{Z_{\text{mean\_adj}} + Z_{\text{mean\_k}} + Z_{\text{cluster\_coef}} + Z_{\text{density\_raw}}}{4}$$

and $Z_{\text{connectivity}}$ evaluates whether intramodular hub feature rankings are conserved between reference and test networks:

$$Z_{\text{connectivity}} = \frac{Z_{\text{kIM}} + Z_{\text{kME}}}{2}, \quad Z = \frac{\text{obs} - \mu_{\text{perm}}}{\sigma_{\text{perm}}}$$

- **Preservation Thresholds**:
  - $Z < 2$ (dashed red line): No statistical evidence of module preservation.
  - $2 \le Z \le 10$ (dashed orange line): Moderate module preservation.
  - $Z > 10$ (dashed green line): Strong, statistically significant module preservation.

## Zi-Pi Keystone Ecological Role Plot: `type = "zipi"`

Keystone taxa play disproportionately vital roles in maintaining community structure. The Zi-Pi classification framework (Guimerà & Amaral, *Nature* 2005; Deng et al., *Science* 2012; Tao Wen et al., *iMeta* 2025) maps within-module connectivity z-score ($Z_i$) against among-module participation coefficient ($P_i$):

- **Within-module connectivity ($Z_i$)**:
  $$Z_i = \frac{k_{i, s_i} - \bar{k}_{s_i}}{\sigma_{k_{s_i}}}$$

4. **Network hubs** ($Z_i > 2.5, P_i > 0.62$): Super-generalists critical to global network integrity.
