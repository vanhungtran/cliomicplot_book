7  Differential Expression: Volcano Plots and DEG Contrasts

  • Show All Code
  • Hide All Code
  • View Source

High-throughput transcriptomics and proteomics evaluate thousands of features simultaneously. Volcano plots and contrast matrices map effect size (\log_2\text{FC}) against statistical significance (-\log_{10}P).

7.1 Volcano Plots: type = "volcano"

A volcano plot places \log_2(\text{Fold Change}) on the horizontal axis and -\log_{10}(P\text{-value}) or -\log_{10}(\text{FDR}) on the vertical axis:

\text{Significance Quadrants}: \begin{cases} \text{Up-regulated}: & \log_2\text{FC} \ge \tau_{\text{FC}} \quad \text{and} \quad -\log_{10}(P) \ge \tau_P \\ \text{Down-regulated}: & \log_2\text{FC} \le -\tau_{\text{FC}} \quad \text{and} \quad -\log_{10}(P) \ge \tau_P \\ \text{Non-significant}: & \text{otherwise} \end{cases}

7.2 Contrast 1: Atopic Dermatitis vs. Control Skin (NCBI GEO GSE121212)

Using the bundled dermatology series dataset (geo_dermatology_series_de.rds), we evaluate lesional skin from patients with Atopic Dermatitis (AD) against Healthy Controls (HC):

Show R code 
library(cliomicplot)
library(ggplot2)

data_file <- system.file("extdata", "geo_dermatology_series_de.rds", package = "cliomicplot")
series <- readRDS(data_file)

# Inspect available contrasts
names(series)
[1] "ad_vs_hc"       "pso_vs_hc"      "ad_vs_pso"      "treatment_meta"
[5] "series_tidy"
Show R code 
# AD vs. Healthy Control volcano plot
ad_labels <- c("SERPINB4", "CCL18", "S100A7", "LCE3A", "SPRR2G", "ALOX15", "GPLD1", "SPTLC3")

p_ad_volc <- cliplot(
  -log10(padj) ~ log2FC,
  data = series$ad_vs_hc,
  type = type_volcano(
    pval_cutoff  = 0.01,
    fc_cutoff    = 1.5,
    point_size   = 1.8,
    point_alpha  = 0.60,
    label_genes  = ad_labels,
    max_overlaps = 25
  ),
  palette  = "nature",
  preset   = "nature",
  title    = "NCBI GEO GSE121212: Atopic Dermatitis vs. Healthy Skin",
  subtitle = "Bulk RNA-seq | FDR < 0.01, |log2FC| > 1.50"
)
p_ad_volc

Biological observations: - Marked upregulation of Epidermal Differentiation Complex (EDC) genes (LCE3A, SPRR2G, S100A7) and Th2 chemokines (CCL18, SERPINB4). - Selective downregulation of ceramide biosynthesis enzymes (SPTLC3, \log_2\text{FC} = -0.57).

p_pso_volc

Key features: - Massive induction of beta-defensins: DEFB4A (\log_2\text{FC} = +10.00, P_{\text{adj}} = 2.02 \times 10^{-75}) and DEFB4B (\log_2\text{FC} = +9.49). - Elevated calprotectin subunits (S100A8, S100A9) and elafin (PI3).

## Volcano Plots: `type = "volcano"`

A volcano plot places $\log_2(\text{Fold Change})$ on the horizontal axis and $-\log_{10}(P\text{-value})$ or $-\log_{10}(\text{FDR})$ on the vertical axis:

$$\text{Significance Quadrants}: \begin{cases}
\text{Up-regulated}: & \log_2\text{FC} \ge \tau_{\text{FC}} \quad \text{and} \quad -\log_{10}(P) \ge \tau_P \\
\text{Down-regulated}: & \log_2\text{FC} \le -\tau_{\text{FC}} \quad \text{and} \quad -\log_{10}(P) \ge \tau_P \\

\end{cases}$$
