18  Case Study: Immuno-Oncology Biomarkers and Trial Endpoints

  • Show All Code
  • Hide All Code
  • View Source

Immune checkpoint inhibitors (anti-PD-1 / anti-PD-L1) have altered treatment paradigms in solid tumors. This case study illustrates an integrated clinical trial reporting workflow combining survival outcomes, subgroup hazard ratios, and RECIST 1.1 response kinetics.

18.1 Clinical Trial Background

In a randomized Phase III trial evaluating anti-PD-1 immunotherapy versus standard chemotherapy in advanced non-small cell lung cancer, primary endpoints include Overall Survival (OS) and Objective Response Rate (ORR). Key predictive biomarkers include tumor PD-L1 Tumor Proportion Score (TPS: <1\%, 1\text{--}49\%, \ge 50\%).

18.2 Step 1: Overall Survival (Kaplan-Meier with Aligned Risk Table)

Code 
library(cliomicplot)
library(survival)

set.seed(88)
n <- 160
io_surv <- data.frame(
  time   = rexp(n, rate = c(rep(0.035, 80), rep(0.065, 80))),
  status = sample(c(0, 1), n, replace = TRUE, prob = c(0.2, 0.8)),
  arm    = factor(rep(c("Anti-PD-1 Monotherapy", "Chemotherapy"), each = 80))
)

p_km <- cliplot(
  Surv(time, status) ~ arm,
  data   = io_surv,
  type   = "km",
  preset = "nature",
  title  = "Overall Survival: Anti-PD-1 Immunotherapy vs Standard Chemotherapy"
)
p_km

18.3 Step 2: Treatment Consistency Across PD-L1 Subgroups (Forest Plot)

Code 
io_subgroups <- data.frame(
  Variable = c("Overall Intention-to-Treat", "PD-L1 TPS >= 50%", "PD-L1 TPS 1-49%", "PD-L1 TPS < 1%"),
  HR       = c(0.68, 0.49, 0.72, 0.91),
  CI_low   = c(0.55, 0.36, 0.54, 0.71),
  CI_high  = c(0.84, 0.67, 0.96, 1.16)
)

p_forest <- cliplot(
  HR ~ Variable,
  data   = io_subgroups,
  type   = type_forest(
    ref_line    = TRUE,
    ref_val     = 1.0,
    log_scale   = TRUE,
    sort        = TRUE,
    stripe      = TRUE,
    show_values = TRUE
  ),
  preset = "lancet",
  title  = "Hazard Ratios for Overall Survival by PD-L1 Expression Status"
)
p_forest

18.4 Step 3: Tumor Burden Kinetics (Waterfall Plot)

Code 
set.seed(42)
n_eval <- 45
pat_ids <- paste0("PT-", sprintf("%03d", 1:n_eval))
changes <- sort(rnorm(n_eval, mean = -22, sd = 38), decreasing = TRUE)

wf_io <- data.frame(
  Patient = factor(pat_ids, levels = pat_ids),
  Change  = changes
)

p_wf <- cliplot(
  Change ~ Patient,
  data   = wf_io,
  type   = type_waterfall(
    response_thresholds = c("PD" = 20, "PR" = -30),
    bar_width           = 0.72
  ),
  preset = "science",
  title  = "Best Percentage Change in Target Lesion Sum of Longest Diameters"
)
p_wf
