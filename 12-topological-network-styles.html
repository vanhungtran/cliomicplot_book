Visualizing topological differences across multiple conditions requires layout algorithms that distinguish intra-network connections from cross-network alignments. cliplot_cross_network_graph() implements 8 distinct journal layout presets.

12.1 The 8 Topological Layout Styles

Preset Layout Architecture Target Application Visual Characteristics
force Force-directed Fruchterman-Reingold Organic community clustering Spring-embedded repulsion, edge-weighted bundling
hierarchical Stratified flow / tree Upstream/downstream causal pathways Linear vertical/horizontal flow across tiers
bipartite Dual parallel vertical axes Host-microbe or Drug-target pairing Two opposing columns with cross-links between them
radial Central hub-and-spoke Keystone taxa / master regulator analysis Central keystone circle with peripheral satellites
lancet Lancet minimal editorial High-impact clinical journals Muted grey palette, ultra-clean monochrome framing
concentric Concentric circular orbital rings Multi-layered molecular hierarchy Dashed orbital guide tracks, radial alignment
bipolar Opposing magnetic dipolar fields Case vs Control topological rewiring Polar coordinate layout with divergent magnetic poles
science Jewel-toned Science palette Science, Science Advances Sapphire Navy, Ruby Crimson, Emerald, Amethyst

12.2 Node-Level Cross-Network Graph

Code 
library(cliomicplot)

# Generate reproducible cross-network graph data
demo_net <- generate_demo_cross_network()

# Style 1: Force-directed Nature style
p_force <- cliplot_cross_network_graph(
  nodes       = demo_net$nodes,
  edges       = demo_net$edges,
  cross_edges = demo_net$cross_edges,
  level       = "node",
  preset      = "nature",
  scifig      = TRUE,
  title       = "Cross-Network Topological Architecture (Nature Style)"
)
p_force

12.2.4 Style 9: Modular Polygon Ring Layout (PolygonRrClusterG, type_polygon_network())

Community co-occurrence networks frequently partition into distinct functional modules. Placing module members along circular rings positioned at the vertices of a macro-polygon (PolygonClusterG and PolygonRrClusterG in ggClusterNet 2, Wen et al. iMeta 2025) cleanly separates dense intra-module edges from inter-cluster links.

In type_polygon_network(adaptive_radius = TRUE), module ring radii scale with \sqrt{N_k / \bar{N}}, allocating area proportional to module richness:

Code 
p_poly <- cliplot(
  type  = type_polygon_network(adaptive_radius = TRUE, label_size = 2.4),
  title = "Modular Polygon Ring Co-Occurrence Topology (PolygonRrClusterG)"
)
p_poly

12.2.5 Style 10: Transkingdom & Multi-Omics Bipartite Networks (type_bipartite())

Cross-domain associations—such as interactions between bacterial and fungal communities, or gut microbiota coupled with serum metabolomics—require bipartite layouts with signed correlation edges:

Code 
p_bip_net <- cliplot(
  type  = type_bipartite(domain_a = "Gut Microbiota", domain_b = "Serum Metabolites", layout = "bipolar"),
  title = "Transkingdom Cross-Domain Network (Microbiota vs Metabolites)"
)
p_bip_net

# Multi-Group Comparative Networks Across 8 Journal Styles

Visualizing topological differences across multiple conditions requires layout algorithms that distinguish intra-network connections from cross-network alignments. `cliplot_cross_network_graph()` implements 8 distinct journal layout presets.

## The 8 Topological Layout Styles

| Preset | Layout Architecture | Target Application | Visual Characteristics |
|:---|:---|:---|:---|
| `force` | Force-directed Fruchterman-Reingold | Organic community clustering | Spring-embedded repulsion, edge-weighted bundling |
| `hierarchical`| Stratified flow / tree | Upstream/downstream causal pathways | Linear vertical/horizontal flow across tiers |
| `bipartite` | Dual parallel vertical axes | Host-microbe or Drug-target pairing | Two opposing columns with cross-links between them |
| `radial` | Central hub-and-spoke | Keystone taxa / master regulator analysis| Central keystone circle with peripheral satellites |
| `lancet` | Lancet minimal editorial | High-impact clinical journals | Muted grey palette, ultra-clean monochrome framing |
| `concentric` | Concentric circular orbital rings | Multi-layered molecular hierarchy | Dashed orbital guide tracks, radial alignment |
| `bipolar` | Opposing magnetic dipolar fields | Case vs Control topological rewiring | Polar coordinate layout with divergent magnetic poles |
| `science` | Jewel-toned Science palette | *Science*, *Science Advances* | Sapphire Navy, Ruby Crimson, Emerald, Amethyst |

### Style 9: Modular Polygon Ring Layout (`PolygonRrClusterG`, `type_polygon_network()`)

Community co-occurrence networks frequently partition into distinct functional modules. Placing module members along circular rings positioned at the vertices of a macro-polygon (`PolygonClusterG` and `PolygonRrClusterG` in `ggClusterNet 2`, Wen et al. *iMeta* 2025) cleanly separates dense intra-module edges from inter-cluster links.

In `type_polygon_network(adaptive_radius = TRUE)`, module ring radii scale with $\sqrt{N_k / \bar{N}}$, allocating area proportional to module richness:

```{r polygon-ring-demo, fig.width=7.5, fig.height=7.5}
p_poly <- cliplot(
```
