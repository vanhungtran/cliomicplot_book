5  Oncology Trajectories: Waterfall and Swimmer Plots

  • Show All Code

Evaluating patient responses in oncology trials requires tracking both the magnitude of tumor shrinkage (RECIST 1.1) and the duration of response over time. cliomicplot provides waterfall, swimmer, and longitudinal trajectory visualizations.

5.1 RECIST 1.1 Waterfall Plots: type = "waterfall"

Waterfall plots rank individual patients by the maximum percentage change in target lesion sum of longest diameters from baseline:

\Delta\% = \frac{\text{SLD}_{\text{post}} - \text{SLD}_{\text{baseline}}}{\text{SLD}_{\text{baseline}}} \times 100

Standard RECIST 1.1 thresholds define response categories: - Partial Response (PR): \Delta\% \le -30\% - Progressive Disease (PD): \Delta\% \ge +20\% - Stable Disease (SD): Between -30\% and +20\%

Show R code 
library(cliomicplot)
library(ggplot2)

set.seed(42)
n_pts <- 30

imtrial <- data.frame(
  Patient    = paste0("PT-", sprintf("%02d", 1:n_pts)),
  BestChange = sort(rnorm(n_pts, mean = -22, sd = 32)),
  BestResp   = sample(c("CR", "PR", "SD", "PD"), n_pts,
                      replace = TRUE, prob = c(0.10, 0.30, 0.35, 0.25)),
  Duration   = pmax(2, round(rnorm(n_pts, mean = 16, sd = 7), 1)),
  Ongoing    = sample(c(TRUE, FALSE), n_pts, replace = TRUE, prob = c(0.4, 0.6))
)

clitheme("broadsheet")

p_wf <- cliplot(
  BestChange ~ Patient,
  data = imtrial,
  type = type_waterfall(
    show_labels         = FALSE,
    n_skip_label        = 1,
    bar_width           = 0.72,
    response_thresholds = c("PD" = 20, "PR" = -30)
  ),
  title    = "Best Tumor Response from Baseline (Waterfall)",
  subtitle = "RECIST v1.1 Thresholds: PD (+20%) and PR (-30%)",
  ylab     = "Best % Change in Target Lesions",
  legend   = "bottom"
) +
  theme(axis.text.x = element_text(angle = 45, hjust = 1, size = 6.5))

p_wf

5.2 Swimmer Plots with Ongoing Arrows: type = "swimmer"

Following Clinical Archetype 13, swimmer plots track individual patient treatment timelines. Patients actively continuing therapy at database lock are distinguished by arrowheads at their bar tips (ongoing = "Ongoing"), and key clinical events are overlaid with RECIST glyphs:

Show R code 
set.seed(123)
n_events_per_pt <- sample(1:3, n_pts, replace = TRUE)
events_list <- lapply(seq_len(n_pts), function(i) {
  n_ev <- n_events_per_pt[i]
  dur  <- imtrial$Duration[i]
  times <- sort(round(runif(n_ev, min = 0.5, max = pmax(1.0, dur - 0.8)), 1))
  ev_types <- sample(c("Progression", "AE", "Dose Reduction", "Response", "Surgery"),
                     n_ev, replace = TRUE, prob = c(0.25, 0.25, 0.20, 0.20, 0.10))
  data.frame(ID = imtrial$Patient[i], Time = times, Event = ev_types)
})
events_df <- do.call(rbind, events_list)

clitheme("cell")

p_swim <- cliplot(
  Duration ~ Patient,
  data = imtrial,
  type = type_swimmer(
    bar_fill      = "BestResp",
    ongoing       = "Ongoing",
    event_times   = events_df,
    show_duration = TRUE,
    bar_alpha     = 0.85,
    bar_linewidth = 4.0
  ),
  bar_palette = "jama",
  title       = "Patient Treatment Trajectories (Swimmer)",
  subtitle    = "Arrows indicate ongoing therapy at data lock | Overlay: RECIST Events",
  xlab        = "",
  ylab        = "Time on Study (months)",
  legend      = "bottom"
) +
  theme(axis.text.y = element_text(size = 7))

p_swim

5.3 Longitudinal Recovery Trajectories with Standard Error Bars: type_trajectory()

In longitudinal trials and cohort recovery tracking, patient-level heterogeneity is evaluated across repeated clinic visits and follow-up milestones (Clinical Archetype 4). type_trajectory() overlays semi-transparent individual patient spaghetti paths with bold group mean trajectories and vertical standard error bars with horizontal crossbar caps (errorbar = "se").

We follow the 4-step progressive pipeline:

5.3.1 Step 1: Basic Mean Trajectory Geometry

A single formula call renders the baseline trajectory with raw patient spaghetti paths and overall mean line:

Show R code 
# Generate reproducible 2-arm longitudinal trial cohort with recovery milestone
set.seed(42)
n_per_arm <- 20
visits <- c("Baseline", "Week 2", "Week 4", "Week 8", "Recovery")
arms <- c("Placebo", "Biologic (300mg)")

df_trial <- expand.grid(
  Subject = paste0("S_", sprintf("%03d", 1:(n_per_arm * 2))),
  Visit   = visits
)
df_trial$Treatment <- factor(
  ifelse(as.numeric(gsub("S_", "", df_trial$Subject)) <= n_per_arm, "Placebo", "Biologic (300mg)"),
  levels = arms
)
df_trial$Visit <- factor(df_trial$Visit, levels = visits)

eff_map <- c("Baseline" = 0, "Week 2" = -8, "Week 4" = -18, "Week 8" = -28, "Recovery" = -32)
df_trial$Score <- 55 + rnorm(nrow(df_trial), 0, 5.5)
is_bio <- df_trial$Treatment == "Biologic (300mg)"
for (v in visits) {
  mask <- is_bio & (df_trial$Visit == v)
  df_trial$Score[mask] <- df_trial$Score[mask] + eff_map[v] + rnorm(sum(mask), 0, 3.5)
}

# Step 1: Basic unstratified trajectory
p_traj_step1 <- cliplot(
  Score ~ Visit | Subject,
  data = df_trial[df_trial$Treatment == "Biologic (300mg)", ],
  type = "trajectory"
)
p_traj_step1

5.3.2 Step 2: Add Scientific Color Mapping Across Treatment Arms

Mapping the formula to Score ~ Visit | Treatment stratifies both patient spaghetti paths and bold mean trajectories by treatment arm using a publication palette (palette = "nature"):

Show R code 
p_traj_step2 <- cliplot(
  Score ~ Visit | Treatment,
  data    = df_trial,
  type    = "trajectory",
  palette = "nature"
)
p_traj_step2

5.3.3 Step 3: Add Journal Template and Standard Error Crossbars

Configuring type_trajectory() with standard error bars (show_errorbar = TRUE, errorbar = "se"), white-filled circular markers (point_fill = "white"), horizontal dodging (dodge = 0.16), and theme = "nature" produces a clean publication figure:

Show R code 
p_traj_step3 <- cliplot(
  Score ~ Visit | Treatment,
  data    = df_trial,
  type    = type_trajectory(
    show_errorbar  = TRUE,
    errorbar       = "se",
    errorbar_width = 0.15,
    errorbar_lwd   = 0.85,
    point_shape    = 21,
    point_size     = 3.4,
    point_fill     = "white",
    dodge          = 0.16,
    severity_bands = NULL
  ),
  palette = "nature",
  theme   = "nature",
  title   = "Mean Trajectory with Standard Error Bars Across Recovery Time Points",
  subtitle = "Biologic vs Placebo with SE crossbars and recovery follow-up milestone",
  xlab    = "Study Visit / Timeline",
  ylab    = "Clinical Severity Score (Points)"
)
p_traj_step3

At the primary endpoint (Week 8) and post-treatment recovery milestone, between-arm differences can be tested and annotated with comparison bracket bars:
