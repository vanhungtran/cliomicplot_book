23  Model-Based Meta-Analysis (MBMA) and Placebo Kinetics in Clinical Trials

  • Show All Code
  • Hide All Code
  • View Source

Model-based meta-analysis (MBMA) quantifies longitudinal response dynamics across clinical trials by integrating non-linear pharmacological models with patient covariates and trial design factors. In moderate-to-severe atopic dermatitis (AD), placebo response rates exhibit wide variability (from 5% to over 35% across Phase 2 and Phase 3 trials), complicating comparative effectiveness and risk-benefit interpretations.

This case study demonstrates the replication and visual grammar of the landmark MBMA study by Serrano et al. (CPT Pharmacometrics Syst Pharmacol 2025/2026, doi:10.1002/psp4.13251). Analyzing 17 randomized controlled trials comprising 4,812 patients across Phase 2 and Phase 3 programs, the authors developed a non-linear longitudinal model identifying two primary determinants of placebo response: baseline disease severity and concomitant topical corticosteroid (TCS) use.

We replicate the core publication figures using cliomicplot:

  1. Figure 1: Longitudinal TCS Concomitant Therapy Effects (Raw observed arm data, model projections, and the 1.85 response ratio).
  2. Figure 2 (figure-p0008-000.jpg): Baseline Disease Severity Tertiles and Continuous EASI Decrement (Panels A–D).
  3. Figure 3 (figure-p0009-000.jpg): Trial Design Matrix Heatmap, 10-Point EASI Divergence, and Phase 2 vs. Phase 3 Benchmark Validation (Panels A–C).

23.1 1. Pharmacometric Model Architecture & Longitudinal Rate Equations

The MBMA framework specifies a logit non-linear model for the probability P_{ij} of placebo EASI-75 response in trial arm i at week t_j:

\text{logit}(P_{ij}) = E_{\text{base}} + \Big(E_{\text{max}} + \theta_{\text{TCS}} \cdot I_{\text{TCS}} + \theta_{\text{EASI}} \cdot (\text{EASI}_i - 29)\Big) \cdot \big(1 - e^{-k \cdot t_j}\big)

\text{EASI-75 Placebo Rate (\%)} = \frac{100}{1 + e^{-\text{logit}(P_{ij})}}

Parameter Estimate 95% CI Pharmacometric Interpretation
E_{\text{base}} -4.97 -5.47 to -4.45 Baseline log-odds of response at t = 0 (Week 0)
E_{\text{max}} 3.21 2.71 to 3.73 Asymptotic maximum additional placebo response over time
k 0.291\text{ wk}^{-1} 0.227 to 0.353 First-order onset rate constant (half-life t_{1/2} = 2.38 weeks)
\theta_{\text{TCS}} 0.774 0.567 to 0.983 Additive effect of concomitant topical corticosteroids on E_{\text{max}}
\theta_{\text{EASI}} -0.0486 -0.0721 to -0.0260 Decrement in E_{\text{max}} per 1-point increase in mean baseline EASI (centered at 29)
\omega^2_{\eta} 0.0396 — Inter-trial variability variance in E_{\text{max}}
\omega^2_{\gamma} 0.138 — Inter-trial variability variance in onset rate k

23.2 2. Figure 1: Concomitant TCS Therapy and Placebo Response Doubling

Figure 1 illustrates how concomitant TCS therapy nearly doubles placebo response rates relative to monotherapy (RR = 1.85). At Week 16, projected EASI-75 placebo rates are 14.3% (95% CI: 12.7%–16.0%) for monotherapy versus 26.4% (95% CI: 23.4%–29.3%) for +TCS study arms under mean baseline EASI conditions (EASI = 29).

23.2.1 Reproducible R Code

Show R code: Figure 1 Concomitant TCS Trajectories 
library(ggplot2)
library(dplyr)
library(patchwork)
library(cliomicplot)

# 1. Non-linear MBMA model equation
calc_placebo_easi75 <- function(week, tcs = FALSE, easi = 29) {
  Ebase <- -4.97; Emax <- 3.21; k <- 0.291; theta_TCS <- 0.774; theta_EASI <- -0.0486
  I_TCS <- if (tcs) 1 else 0
  lp <- Ebase + (Emax + theta_TCS * I_TCS + theta_EASI * (easi - 29)) * (1 - exp(-k * week))
  100 / (1 + exp(-lp))
}

# 2. Simulation grid for model curves
time_seq <- seq(0, 16, length.out = 80)
model_df <- rbind(
  data.frame(week = time_seq, tcs = "Monotherapy",
             rate = calc_placebo_easi75(time_seq, tcs = FALSE, easi = 29),
             ymin = calc_placebo_easi75(time_seq, tcs = FALSE, easi = 29) * 0.88,
             ymax = calc_placebo_easi75(time_seq, tcs = FALSE, easi = 29) * 1.12),
  data.frame(week = time_seq, tcs = "With TCS",
             rate = calc_placebo_easi75(time_seq, tcs = TRUE, easi = 29),
             ymin = calc_placebo_easi75(time_seq, tcs = TRUE, easi = 29) * 0.89,
             ymax = calc_placebo_easi75(time_seq, tcs = TRUE, easi = 29) * 1.11)
)

# 3. Digitized trial-level observed points
obs_pts <- data.frame(
  week = c(4, 4, 8, 8, 12, 12, 16, 16, 4, 8, 12, 16),
  rate = c(6, 10, 11, 14, 13, 15, 14, 16, 12, 22, 28, 27),
  tcs  = c(rep("Monotherapy", 8), rep("With TCS", 4)),
  n    = c(224, 233, 248, 309, 567, 557, 1196, 564, 270, 110, 264, 108)
)

# Panel A & B: Model trajectory with type_mbma_trajectory()
p1_traj <- cliplot(
  rate ~ week,
  data = model_df,
  by = model_df$tcs,
  type = type_mbma_trajectory(
    show_points = FALSE,
    show_ribbon = TRUE,
    line_width = 1.2,
    plateau_week = 12,
    plateau_text = "94% plateau at Wk 12",
    colors = c("Monotherapy" = "#2980B9", "With TCS" = "#E67E22")
  )
) +
  geom_point(data = obs_pts, aes(x = week, y = rate, size = n, color = tcs), alpha = 0.65) +
  scale_size_continuous(range = c(2.0, 6.0), name = "Trial Arm N") +
  labs(
    title = "EASI-75 Placebo Trajectory by Concomitant TCS",
    subtitle = "Model curves at mean baseline EASI = 29 with digitized RCT observations",
    x = "Trial Duration (Weeks)",
    y = "Placebo EASI-75 Response (%)"
  ) +
  clitheme(preset = "nature", base_size = 11) +
  theme(legend.position = "bottom")

# Panel C: Longitudinal Response Ratio (TCS / Monotherapy)
rr_df <- data.frame(
  week = time_seq[time_seq >= 1],
  rr   = calc_placebo_easi75(time_seq[time_seq >= 1], tcs = TRUE) /
         calc_placebo_easi75(time_seq[time_seq >= 1], tcs = FALSE)
)
rr_df$ymin <- rr_df$rr * 0.86
rr_df$ymax <- rr_df$rr * 1.14

p1_rr <- ggplot(rr_df, aes(x = week, y = rr)) +
  geom_ribbon(aes(ymin = ymin, ymax = ymax), fill = "#7F8C8D", alpha = 0.2) +
  geom_line(color = "#2C3E50", linewidth = 1.1) +
  geom_hline(yintercept = 1.85, linetype = "dashed", color = "#E74C3C", linewidth = 0.7) +
  annotate("text", x = 12.5, y = 1.95, label = "RR = 1.85 at Week 16\n(95% CI: 1.57 - 2.17)",
           size = 3.2, color = "#E74C3C", fontface = "bold") +
  scale_y_continuous(limits = c(1.0, 2.5), breaks = seq(1.0, 2.5, 0.5)) +
  labs(
    title = "Longitudinal Response Ratio (+TCS / Monotherapy)",
    subtitle = "Relative increase in placebo response attributable to background TCS",
    x = "Trial Duration (Weeks)",
    y = "Response Ratio (RR)"
  ) +
  clitheme(preset = "nature", base_size = 11)

p1_composite <- p1_traj | p1_rr

23.3 3. Figure 2: Baseline Disease Severity Tertiles and Continuous EASI Decrement

Figure 2 demonstrates that enrolled patient disease severity is a major determinant of placebo response: study arms enrolling milder populations (low baseline EASI) achieve higher placebo rates, whereas severe populations exhibit low placebo response.

  • Panel A (Raw Data by Tertiles): Trials without concomitant therapy grouped into baseline EASI tertiles: Low (EASI pprox 19, green), Medium (EASI pprox 29, amber), and High (EASI pprox 34, purple).
  • Panel B (Model Projections by Tertile): Model trajectories aligning with the observed tertile divergence over 16 weeks.
  • Panel C (Continuous EASI Effect, Monotherapy): Model-projected response rates at Week 12 and Week 16 declining across baseline EASI from 15 to 40 (RR = 0.961 per 1-point increase).
  • Panel D (Continuous EASI Effect, +TCS): Parallel downward trajectories shifted upward by the additive TCS effect.

23.4 4. Figure 3: MBMA Trial Design Grid and Benchmark Validation

Figure 3 demonstrates how the MBMA framework enables clinical trial simulation, protocol exploration, and virtual placebo cohort benchmarking:

  • Panel A (Trial Design Grid Heatmap): Comprehensive simulation matrix of model-estimated placebo response rates across baseline EASI scores (20, 24, 28, 32, 36, 40), assessment timepoints (Week 8, Week 12, Week 16), and design policies (No Concomitant vs. TCS Concomitant). Each tile shows the central estimate in bold with its \pm 95\% CI margin underneath.
  • Panel B (10-Point EASI Divergence): Paired longitudinal trajectories for baseline EASI = 24 versus 34 without concomitant therapy, demonstrating a response ratio of 0.665 (95% CI: 0.549–0.812) at Week 12.
  • Panel C (Phase 2 vs. Phase 3 Benchmark Validation): Distribution of observed trial arms across development phases overlaid on the model prediction band at baseline EASI = 29 (13.5% [11.8%–15.3%]), validating that placebo response patterns are consistent between Phase 2 and Phase 3 and supporting control borrowing.

23.4.1 Reproducible R Code

Show R code: Figure 3 Trial Design Grid and Benchmark Composite 
library(ggplot2)
library(dplyr)
library(patchwork)
library(cliomicplot)

# 1. Panel A: Trial Design Grid Simulation Data
grid_data <- expand.grid(
  easi = factor(c(40, 36, 32, 28, 24, 20), levels = c(40, 36, 32, 28, 24, 20)),
  week = factor(c("Week 8", "Week 12", "Week 16"), levels = c("Week 8", "Week 12", "Week 16")),
  design = c("No Concomitant", "TCS Concomitant"),
  stringsAsFactors = FALSE
)

grid_data$rate <- mapply(function(e, w, d) {
  wk_num <- as.numeric(gsub("Week ", "", w))
  e_num  <- as.numeric(as.character(e))
  tcs_flag <- (d == "TCS Concomitant")
  calc_placebo_easi75(wk_num, tcs = tcs_flag, easi = e_num)
}, grid_data$easi, grid_data$week, grid_data$design)

# Approximate 95% CI margins (± margin)
grid_data$ci_margin <- grid_data$rate * 0.11

p3a <- cliplot(
  easi ~ week,
  data = grid_data,
  by = grid_data$design,
  type = type_mbma_grid(
    ci_margin = "ci_margin",
    palette = "blues",
    text_size = 3.3,
    ci_size = 2.3
  )
) +
  labs(
    title = "A  Trial Design Exploration Grid (EASI-75 Placebo Rates)",
    subtitle = "Cell values: Model projection ± 95% CI across baseline severity and timepoints",
    x = "Assessment Timepoint",
    y = "Study Arm Baseline EASI Score"
  ) +
  clitheme(preset = "nature", base_size = 10) +
  theme(legend.position = "bottom")

  scale_x_continuous(breaks = c(4, 8, 12, 16)) +
  scale_y_continuous(limits = c(0, 26), breaks = seq(0, 25, 5)) +

    title = "B  10-Point EASI Divergence (24 vs 34)",
    x = "Trial Duration (Weeks)",
    y = "Placebo EASI-75 (%)"
  ) +
  clitheme(preset = "nature", base_size = 10) +

# 3. Panel C: Benchmark Model vs Observed Validation
bench_df <- data.frame(

  ) +

# Assemble Figure 3 multi-panel layout

# Model-Based Meta-Analysis (MBMA) and Placebo Kinetics in Clinical Trials

Model-based meta-analysis (MBMA) quantifies longitudinal response dynamics across clinical trials by integrating non-linear pharmacological models with patient covariates and trial design factors. In moderate-to-severe atopic dermatitis (AD), placebo response rates exhibit wide variability (from 5% to over 35% across Phase 2 and Phase 3 trials), complicating comparative effectiveness and risk-benefit interpretations.

This case study demonstrates the replication and visual grammar of the landmark MBMA study by *Serrano et al.* (*CPT Pharmacometrics Syst Pharmacol* 2025/2026, [doi:10.1002/psp4.13251](https://doi.org/10.1002/psp4.13251)). Analyzing 17 randomized controlled trials comprising 4,812 patients across Phase 2 and Phase 3 programs, the authors developed a non-linear longitudinal model identifying two primary determinants of placebo response: **baseline disease severity** and **concomitant topical corticosteroid (TCS) use**.

We replicate the core publication figures using `cliomicplot`:

1. **Figure 1**: Longitudinal TCS Concomitant Therapy Effects (Raw observed arm data, model projections, and the 1.85 response ratio).
2. **Figure 2 (`figure-p0008-000.jpg`)**: Baseline Disease Severity Tertiles and Continuous EASI Decrement (Panels A–D).
3. **Figure 3 (`figure-p0009-000.jpg`)**: Trial Design Matrix Heatmap, 10-Point EASI Divergence, and Phase 2 vs. Phase 3 Benchmark Validation (Panels A–C).

---

## 1. Pharmacometric Model Architecture & Longitudinal Rate Equations

The MBMA framework specifies a logit non-linear model for the probability $P_{ij}$ of placebo EASI-75 response in trial arm $i$ at week $t_j$:

$$\text{logit}(P_{ij}) = E_{\text{base}} + \Big(E_{\text{max}} + \theta_{\text{TCS}} \cdot I_{\text{TCS}} + \theta_{\text{EASI}} \cdot (\text{EASI}_i - 29)\Big) \cdot \big(1 - e^{-k \cdot t_j}\big)$$

$$\text{EASI-75 Placebo Rate (\%)} = \frac{100}{1 + e^{-\text{logit}(P_{ij})}}$$

| Parameter | Estimate | 95% CI | Pharmacometric Interpretation |
|:---|:---|:---|:---|
| $E_{\text{base}}$ | $-4.97$ | $-5.47$ to $-4.45$ | Baseline log-odds of response at $t = 0$ (Week 0) |
| $E_{\text{max}}$ | $3.21$ | $2.71$ to $3.73$ | Asymptotic maximum additional placebo response over time |
| $k$ | $0.291\text{ wk}^{-1}$ | $0.227$ to $0.353$ | First-order onset rate constant (half-life $t_{1/2} = 2.38$ weeks) |
| $\theta_{\text{TCS}}$ | $0.774$ | $0.567$ to $0.983$ | Additive effect of concomitant topical corticosteroids on $E_{\text{max}}$ |
| $\theta_{\text{EASI}}$ | $-0.0486$ | $-0.0721$ to $-0.0260$ | Decrement in $E_{\text{max}}$ per 1-point increase in mean baseline EASI (centered at 29) |
| $\omega^2_{\eta}$ | $0.0396$ | — | Inter-trial variability variance in $E_{\text{max}}$ |
| $\omega^2_{\gamma}$ | $0.138$ | — | Inter-trial variability variance in onset rate $k$ |

library(ggplot2)
library(dplyr)
library(patchwork)
library(cliomicplot)

# 1. Non-linear MBMA model equation
calc_placebo_easi75 <- function(week, tcs = FALSE, easi = 29) {
  Ebase <- -4.97; Emax <- 3.21; k <- 0.291; theta_TCS <- 0.774; theta_EASI <- -0.0486
  I_TCS <- if (tcs) 1 else 0
  lp <- Ebase + (Emax + theta_TCS * I_TCS + theta_EASI * (easi - 29)) * (1 - exp(-k * week))
  100 / (1 + exp(-lp))
}

# 2. Simulation grid for model curves
time_seq <- seq(0, 16, length.out = 80)
model_df <- rbind(
  data.frame(week = time_seq, tcs = "Monotherapy",
             rate = calc_placebo_easi75(time_seq, tcs = FALSE, easi = 29),
             ymin = calc_placebo_easi75(time_seq, tcs = FALSE, easi = 29) * 0.88,
             ymax = calc_placebo_easi75(time_seq, tcs = FALSE, easi = 29) * 1.12),
  data.frame(week = time_seq, tcs = "With TCS",
             rate = calc_placebo_easi75(time_seq, tcs = TRUE, easi = 29),
