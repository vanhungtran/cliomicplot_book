8  Pathway Enrichment and Multi-Omics Abundance Profiles

  • Show All Code

Pathway enrichment and multi-omics profiling aggregate molecular alterations into functional signatures. This chapter covers Gene Set Enrichment Analysis (GSEA), multi-omics pathway enrichment across RNA, single-cell transcriptomics, mass spectrometry proteomics, and microbiome metagenomics, bubble heatmap archetypes, and rank-abundance dynamic range curves.

8.1 Gene Set Enrichment Analysis: type = "gsea" and type = "gsea_running"

Gene Set Enrichment Analysis (Subramanian et al., PNAS 2005) evaluates whether an a priori defined gene set S shows cumulative enrichment at the extremes of a ranked gene list L:

P_{\text{hit}}(S, i) = \sum_{g_j \in S, j \le i} \frac{|r_j|^p}{N_R}, \quad N_R = \sum_{g_j \in S} |r_j|^p

P_{\text{miss}}(S, i) = \sum_{g_j \notin S, j \le i} \frac{1}{N - N_H}

ES(S) = \arg\max_{i} |P_{\text{hit}}(S, i) - P_{\text{miss}}(S, i)|

cliomicplot provides four complementary visualizations for GSEA results: 1. Preranked Enrichment Dot Plot (type = "gsea"): Pathway terms ranked by effect magnitude, with dot size encoding -\log_{10}(\text{FDR}) and fill encoding Normalized Enrichment Score (NES). 2. Three-Tier Running Score Walk Plot (type = "gsea_running"): The classical GSEA profile displaying the cumulative walk curve, gene hit barcode rug, and ranked metric area. 3. Directional Diverging Lollipop Plot (type = "lollipop"): Horizontal effect size bars comparing positive and negative pathway activation. 4. Multi-Phenotype Comparison Matrix (type = type_bubble_diverging()): Cross-condition pathway activity across disease phenotypes and therapeutic stages.

8.2 Multi-Omics Pathway Enrichment: RNA, Single-Cell, Proteomics, and Microbiome

Enrichment analysis connects high-dimensional molecular measurements to cellular mechanisms across four biological layers: - Bulk RNA-seq: Hypergeometric over-representation of differentially expressed genes against background universes. - Single-cell RNA-seq: Cell-level module signature scores tested for lineage specificity by Wilcoxon rank-sum tests. - Mass Spectrometry Proteomics: Moderated t-tests followed by protein complex Fisher exact test fold enrichment. - Microbial Metagenomics: Quality-filtered MetaCyc pathway abundance tests across anatomical sites.

8.2.1 Bulk RNA-seq Over-Representation Analysis (ORA): A to Z Pipeline

In bulk transcriptomics, Over-Representation Analysis tests whether pathway genes appear in the differentially expressed gene set more frequently than expected under the hypergeometric distribution:

P(X \ge k) = \sum_{i=k}^{\min(|S|, |D|)} \frac{\binom{|S|}{i} \binom{N - |S|}{|D| - i}}{\binom{N}{|D|}}

where N is total measured background genes, |D| is significant DEGs, |S| is pathway size in the universe, and k is observed overlap.

The pipeline starts from DESeq2 differential results in geo_dermatology_series_de.rds, identifies upregulated DEGs (p_{\text{adj}} < 0.01, \log_2(\text{FC}) > 1.2), tests pathway gene sets with cli_calc_ora(), and plots Gene Ratio \frac{k}{|D|} with FDR tiers:

Show R code 
# Step 1: Load differential expression results from GEO series
series <- readRDS(system.file("extdata", "geo_dermatology_series_de.rds", package = "cliomicplot"))
de_tbl <- series[["ad_vs_hc"]]

# Step 2: Define DEG criteria and extract measured background universe
de_genes <- de_tbl$gene[which(de_tbl$padj < 0.01 & de_tbl$log2FC > 1.2)]

# Step 3: Define curated cutaneous pathway gene sets

8.2.2 Single-Cell scRNA-seq Lineage Pathway Signatures: A to Z Pipeline

Single-cell pathway scoring computes cell-level activity for gene signatures, then evaluates lineage-specific activation by non-parametric testing:

  1. Standardize expression values across cells (z-score).
  2. Calculate cell-wise signature module scores as mean expression across signature genes.
  3. Quantify active cells (\text{Score} > 0) per lineage.
  4. Test lineage specificity using two-sample Wilcoxon rank-sum tests with Benjamini-Hochberg adjustment.
Show R code 
# Step 1: Construct single-cell expression matrix across 7 lineages
set.seed(42)
cell_types <- c("Basal KC", "Spinous KC", "Suprabasal KC", "CD4+ Th2", "ILC2", "cDC2", "Fibroblasts")
n_per_type <- 60
cells <- rep(cell_types, each = n_per_type)
n_cells <- length(cells)

all_sc_genes <- c(
  "IL4R", "IL13RA1", "STAT6", "CCL17", "CCL22",
  "IL33", "TSLP", "IL1RL1", "S100A8", "S100A9",
  "FLG", "LOR", "IVL", "LCE3A", "SPRR2G",
  "HLA-DRA", "HLA-DRB1", "CD74", "CD86",
  "COL1A1", "COL1A2", "FN1", "MMP1",
  paste0("ControlGene_", 1:25)
)

sc_mat <- matrix(rnorm(n_cells * length(all_sc_genes), mean = 0.5, sd = 0.8),
                 nrow = length(all_sc_genes), ncol = n_cells,
                 dimnames = list(all_sc_genes, paste0("Cell_", seq_len(n_cells))))
sc_mat[sc_mat < 0] <- 0

# Set lineage-specific expression programs
sc_mat[c("IL4R", "IL13RA1", "CCL17", "CCL22"), cells %in% c("CD4+ Th2", "ILC2")] <-
  sc_mat[c("IL4R", "IL13RA1", "CCL17", "CCL22"), cells %in% c("CD4+ Th2", "ILC2")] + 2.8
sc_mat[c("FLG", "LOR", "IVL", "LCE3A", "SPRR2G"), cells %in% c("Spinous KC", "Suprabasal KC")] <-
  sc_mat[c("FLG", "LOR", "IVL", "LCE3A", "SPRR2G"), cells %in% c("Spinous KC", "Suprabasal KC")] + 3.2
sc_mat[c("HLA-DRA", "HLA-DRB1", "CD74", "CD86"), cells == "cDC2"] <-
  sc_mat[c("HLA-DRA", "HLA-DRB1", "CD74", "CD86"), cells == "cDC2"] + 3.5
sc_mat[c("COL1A1", "COL1A2", "FN1", "MMP1"), cells == "Fibroblasts"] <-
  sc_mat[c("COL1A1", "COL1A2", "FN1", "MMP1"), cells == "Fibroblasts"] + 3.0

sc_signatures <- list(
  "Type 2 Cytokines"          = c("IL4R", "IL13RA1", "STAT6", "CCL17", "CCL22"),
  "Alarmin Cascade"           = c("IL33", "TSLP", "IL1RL1", "S100A8", "S100A9"),
  "Epidermal Differentiation" = c("FLG", "LOR", "IVL", "LCE3A", "SPRR2G"),
  "Antigen Presentation"      = c("HLA-DRA", "HLA-DRB1", "CD74", "CD86"),
  "Extracellular Matrix"      = c("COL1A1", "COL1A2", "FN1", "MMP1")
)

# Step 2: Calculate per-cell module signature scores
scale_mat <- t(scale(t(sc_mat)))
module_scores <- vapply(sc_signatures, function(sig_genes) {
  colMeans(scale_mat[intersect(sig_genes, rownames(scale_mat)), , drop = FALSE])
}, numeric(n_cells))

# Step 3: Compute lineage summary metrics and Wilcoxon rank-sum tests
sc_res <- do.call(rbind, lapply(names(sc_signatures), function(sig_name) {
  scores <- module_scores[, sig_name]
  do.call(rbind, lapply(unique(cell_types), function(ct) {
    in_ct <- cells == ct
    pct_active <- mean(scores[in_ct] > 0) * 100
    mean_val   <- mean(scores[in_ct])
    wt <- wilcox.test(scores[in_ct], scores[!in_ct], alternative = "greater")
    data.frame(
      Pathway    = sig_name,
      CellType   = ct,
      PctActive  = pct_active,
      MeanScore  = mean_val,
      pvalue     = wt$p.value,
      stringsAsFactors = FALSE
    )
  }))
}))
sc_res$padj <- p.adjust(sc_res$pvalue, method = "BH")

# Step 4: Render publication circle bubble heatmap
clitheme("cell")

p_sc_path <- cliplot(
  Pathway ~ CellType,
  data = sc_res,
  by   = sc_res$PctActive,
  type = type_bubble_circle(
    palette      = "plasma",
    max_size     = 7.5,
    stroke_col   = "grey35",
    stroke_width = 0.35,
    size_name    = "% Active Cells",
    fill_name    = "Mean Score"
  ),
  extra_data = list(fill = sc_res$MeanScore),
  title      = "Cell-Type-Resolved Pathway Activation in Inflammatory Skin",
  subtitle   = "Point size reflects percentage of active cells; colour reflects mean module score"
)
p_sc_path

Type 2 cytokine cascade localized to CD4+ Th2 and ILC2 cells (100% active, mean scores 1.13 and 1.11, q < 10^{-23}), whereas epidermal differentiation restricted to spinous and suprabasal keratinocytes (q < 10^{-20}).

8.2.3 Mass Spectrometry Proteomics Functional Module Enrichment: A to Z Pipeline

Skin mass spectrometry proteomics measures translated protein quantities. The analysis pipeline:

  1. Tests protein differential abundance between clinical groups with two-sample t-tests (q < 0.01, |\log_2\text{FC}| > 1.0).
  2. Maps significant proteins to functional macromolecular complexes.
  3. Tests module over-representation by Fisher’s exact test.
  4. Computes mean complex \log_2(\text{FC}) to capture directional protein remodeling.
Show R code 
# Step 1: Input LFQ protein intensity matrix across 6 biological replicates
set.seed(42)
proteins <- c(
  "FLG", "LOR", "IVL", "LCE3D", "SPRR2A",
  "DSC1", "DSG1", "DSP", "PKP1",
  "SPINK5", "SERPINB3", "SERPINB4",
  "S100A7", "S100A8", "S100A9", "DEFB4A",
  "ATP5F1A", "NDUFS1", "COX4I1", "SDHA",
  paste0("Protein_Background_", 1:150)
)
n_reps <- 6

lfq_hc <- matrix(rnorm(length(proteins) * n_reps, mean = 24, sd = 0.5), nrow = length(proteins))
lfq_ad <- matrix(rnorm(length(proteins) * n_reps, mean = 24, sd = 0.5), nrow = length(proteins))
rownames(lfq_hc) <- rownames(lfq_ad) <- proteins

# AD-specific protein shifts
lfq_ad[c("FLG", "LOR", "IVL", "LCE3D", "SPRR2A"), ] <- lfq_ad[c("FLG", "LOR", "IVL", "LCE3D", "SPRR2A"), ] - 2.5
lfq_ad[c("DSC1", "DSG1", "DSP", "PKP1"), ] <- lfq_ad[c("DSC1", "DSG1", "DSP", "PKP1"), ] - 1.8
lfq_ad[c("SPINK5", "SERPINB3", "SERPINB4"), ] <- lfq_ad[c("SPINK5", "SERPINB3", "SERPINB4"), ] + 2.4
lfq_ad[c("S100A7", "S100A8", "S100A9", "DEFB4A"), ] <- lfq_ad[c("S100A7", "S100A8", "S100A9", "DEFB4A"), ] + 3.2

# Step 2: Moderated statistical testing for differentially abundant proteins
de_prot <- do.call(rbind, lapply(seq_along(proteins), function(i) {
  tt <- t.test(lfq_ad[i, ], lfq_hc[i, ])
  data.frame(
    Protein = proteins[i],
    log2FC  = mean(lfq_ad[i, ]) - mean(lfq_hc[i, ]),
    pvalue  = tt$p.value,
    stringsAsFactors = FALSE
  )
}))
de_prot$padj <- p.adjust(de_prot$pvalue, method = "BH")
sig_prot <- de_prot$Protein[which(de_prot$padj < 0.01 & abs(de_prot$log2FC) > 1.0)]

# Step 3: Functional macromolecular complexes
prot_modules <- list(
  "Cornified Envelope"          = c("FLG", "LOR", "IVL", "LCE3D", "SPRR2A"),
  "Desmosome Assembly"         = c("DSC1", "DSG1", "DSP", "PKP1"),
  "Serine Peptidase Inhibitors" = c("SPINK5", "SERPINB3", "SERPINB4"),
  "Antimicrobial Peptides"      = c("S100A7", "S100A8", "S100A9", "DEFB4A"),
  "Mitochondrial OxPhos"        = c("ATP5F1A", "NDUFS1", "COX4I1", "SDHA")
)

prot_ora <- cli_calc_ora(sig_prot, prot_modules, background = proteins)
prot_ora$MeanLog2FC <- vapply(prot_ora$Pathway, function(mod) {
  mean(de_prot$log2FC[de_prot$Protein %in% prot_modules[[mod]]])
}, numeric(1))

# Step 4: Compare across clinical phenotypes (AD vs HC and Psoriasis vs HC)
pso_shift <- c(-1.9, -1.4, 3.8, 1.8, 0.1)
prot_multi <- data.frame(
  Module   = rep(prot_ora$Pathway, 2),
  Contrast = rep(c("AD vs HC", "Psoriasis vs HC"), each = nrow(prot_ora)),
  Log2FC   = c(prot_ora$MeanLog2FC, pso_shift),
  negLogQ  = c(-log10(prot_ora$padj), c(4.8, 3.5, 9.2, 5.2, 0.2)),
  stringsAsFactors = FALSE
)

# Step 5: Render diverging bubble heatmap
clitheme("nature")

p_prot_mod <- cliplot(
  Module ~ Contrast,
  data       = prot_multi,
  by         = prot_multi$negLogQ,
  type       = type_bubble_diverging(
    palette      = "nature",
    midpoint     = 0,
    max_size     = 8.0,

## Gene Set Enrichment Analysis: `type = "gsea"` and `type = "gsea_running"`

Gene Set Enrichment Analysis (Subramanian et al., *PNAS* 2005) evaluates whether an a priori defined gene set $S$ shows cumulative enrichment at the extremes of a ranked gene list $L$:

$$P_{\text{hit}}(S, i) = \sum_{g_j \in S, j \le i} \frac{|r_j|^p}{N_R}, \quad N_R = \sum_{g_j \in S} |r_j|^p$$

$$P_{\text{miss}}(S, i) = \sum_{g_j \notin S, j \le i} \frac{1}{N - N_H}$$

$$ES(S) = \arg\max_{i} |P_{\text{hit}}(S, i) - P_{\text{miss}}(S, i)|$$

`cliomicplot` provides four complementary visualizations for GSEA results:
1. **Preranked Enrichment Dot Plot (`type = "gsea"`)**: Pathway terms ranked by effect magnitude, with dot size encoding $-\log_{10}(\text{FDR})$ and fill encoding Normalized Enrichment Score (NES).
2. **Three-Tier Running Score Walk Plot (`type = "gsea_running"`)**: The classical GSEA profile displaying the cumulative walk curve, gene hit barcode rug, and ranked metric area.
3. **Directional Diverging Lollipop Plot (`type = "lollipop"`)**: Horizontal effect size bars comparing positive and negative pathway activation.
4. **Multi-Phenotype Comparison Matrix (`type = type_bubble_diverging()`)**: Cross-condition pathway activity across disease phenotypes and therapeutic stages.

## Multi-Omics Pathway Enrichment: RNA, Single-Cell, Proteomics, and Microbiome

Enrichment analysis connects high-dimensional molecular measurements to cellular mechanisms across four biological layers:
- **Bulk RNA-seq**: Hypergeometric over-representation of differentially expressed genes against background universes.
- **Single-cell RNA-seq**: Cell-level module signature scores tested for lineage specificity by Wilcoxon rank-sum tests.
- **Mass Spectrometry Proteomics**: Moderated $t$-tests followed by protein complex Fisher exact test fold enrichment.
- **Microbial Metagenomics**: Quality-filtered MetaCyc pathway abundance tests across anatomical sites.

### Bulk RNA-seq Over-Representation Analysis (ORA): A to Z Pipeline

In bulk transcriptomics, Over-Representation Analysis tests whether pathway genes appear in the differentially expressed gene set more frequently than expected under the hypergeometric distribution:

$$P(X \ge k) = \sum_{i=k}^{\min(|S|, |D|)} \frac{\binom{|S|}{i} \binom{N - |S|}{|D| - i}}{\binom{N}{|D|}}$$

where $N$ is total measured background genes, $|D|$ is significant DEGs, $|S|$ is pathway size in the universe, and $k$ is observed overlap.

The pipeline starts from DESeq2 differential results in `geo_dermatology_series_de.rds`, identifies upregulated DEGs ($p_{\text{adj}} < 0.01$, $\log_2(\text{FC}) > 1.2$), tests pathway gene sets with `cli_calc_ora()`, and plots Gene Ratio $\frac{k}{|D|}$ with FDR tiers:

### Single-Cell scRNA-seq Lineage Pathway Signatures: A to Z Pipeline

Single-cell pathway scoring computes cell-level activity for gene signatures, then evaluates lineage-specific activation by non-parametric testing:

1. Standardize expression values across cells ($z$-score).
2. Calculate cell-wise signature module scores as mean expression across signature genes.
3. Quantify active cells ($\text{Score} > 0$) per lineage.
4. Test lineage specificity using two-sample Wilcoxon rank-sum tests with Benjamini-Hochberg adjustment.

```{r multiomics-scrna-pathway-atoz, fig.width=8.5, fig.height=5.8}
# Step 1: Construct single-cell expression matrix across 7 lineages
set.seed(42)
cell_types <- c("Basal KC", "Spinous KC", "Suprabasal KC", "CD4+ Th2", "ILC2", "cDC2", "Fibroblasts")
n_per_type <- 60
cells <- rep(cell_types, each = n_per_type)
n_cells <- length(cells)

all_sc_genes <- c(
  "IL4R", "IL13RA1", "STAT6", "CCL17", "CCL22",
  "IL33", "TSLP", "IL1RL1", "S100A8", "S100A9",
  "FLG", "LOR", "IVL", "LCE3A", "SPRR2G",
  "HLA-DRA", "HLA-DRB1", "CD74", "CD86",
  "COL1A1", "COL1A2", "FN1", "MMP1",
  paste0("ControlGene_", 1:25)
)

sc_mat <- matrix(rnorm(n_cells * length(all_sc_genes), mean = 0.5, sd = 0.8),
                 nrow = length(all_sc_genes), ncol = n_cells,
                 dimnames = list(all_sc_genes, paste0("Cell_", seq_len(n_cells))))
sc_mat[sc_mat < 0] <- 0

# Set lineage-specific expression programs
sc_mat[c("IL4R", "IL13RA1", "CCL17", "CCL22"), cells %in% c("CD4+ Th2", "ILC2")] <-
  sc_mat[c("IL4R", "IL13RA1", "CCL17", "CCL22"), cells %in% c("CD4+ Th2", "ILC2")] + 2.8
sc_mat[c("FLG", "LOR", "IVL", "LCE3A", "SPRR2G"), cells %in% c("Spinous KC", "Suprabasal KC")] <-
  sc_mat[c("FLG", "LOR", "IVL", "LCE3A", "SPRR2G"), cells %in% c("Spinous KC", "Suprabasal KC")] + 3.2
sc_mat[c("HLA-DRA", "HLA-DRB1", "CD74", "CD86"), cells == "cDC2"] <-
  sc_mat[c("HLA-DRA", "HLA-DRB1", "CD74", "CD86"), cells == "cDC2"] + 3.5
sc_mat[c("COL1A1", "COL1A2", "FN1", "MMP1"), cells == "Fibroblasts"] <-
  sc_mat[c("COL1A1", "COL1A2", "FN1", "MMP1"), cells == "Fibroblasts"] + 3.0

sc_signatures <- list(
  "Type 2 Cytokines"          = c("IL4R", "IL13RA1", "STAT6", "CCL17", "CCL22"),
  "Alarmin Cascade"           = c("IL33", "TSLP", "IL1RL1", "S100A8", "S100A9"),
  "Epidermal Differentiation" = c("FLG", "LOR", "IVL", "LCE3A", "SPRR2G"),
  "Antigen Presentation"      = c("HLA-DRA", "HLA-DRB1", "CD74", "CD86"),
  "Extracellular Matrix"      = c("COL1A1", "COL1A2", "FN1", "MMP1")
)

# Step 2: Calculate per-cell module signature scores
scale_mat <- t(scale(t(sc_mat)))
module_scores <- vapply(sc_signatures, function(sig_genes) {
  colMeans(scale_mat[intersect(sig_genes, rownames(scale_mat)), , drop = FALSE])
}, numeric(n_cells))

# Step 3: Compute lineage summary metrics and Wilcoxon rank-sum tests
sc_res <- do.call(rbind, lapply(names(sc_signatures), function(sig_name) {
  scores <- module_scores[, sig_name]
  do.call(rbind, lapply(unique(cell_types), function(ct) {
    in_ct <- cells == ct
    pct_active <- mean(scores[in_ct] > 0) * 100
    mean_val   <- mean(scores[in_ct])
    wt <- wilcox.test(scores[in_ct], scores[!in_ct], alternative = "greater")
    data.frame(
      Pathway    = sig_name,
      CellType   = ct,
      PctActive  = pct_active,
      MeanScore  = mean_val,
      pvalue     = wt$p.value,
      stringsAsFactors = FALSE
    )
  }))
}))
sc_res$padj <- p.adjust(sc_res$pvalue, method = "BH")

# Step 4: Render publication circle bubble heatmap
clitheme("cell")

p_sc_path <- cliplot(
  Pathway ~ CellType,
  data = sc_res,
  by   = sc_res$PctActive,
  type = type_bubble_circle(
    palette      = "plasma",
    max_size     = 7.5,
    stroke_col   = "grey35",
    stroke_width = 0.35,
    size_name    = "% Active Cells",
    fill_name    = "Mean Score"
  ),
  extra_data = list(fill = sc_res$MeanScore),
  title      = "Cell-Type-Resolved Pathway Activation in Inflammatory Skin",
  subtitle   = "Point size reflects percentage of active cells; colour reflects mean module score"
)
```

### Mass Spectrometry Proteomics Functional Module Enrichment: A to Z Pipeline

Skin mass spectrometry proteomics measures translated protein quantities. The analysis pipeline:

1. Tests protein differential abundance between clinical groups with two-sample $t$-tests ($q < 0.01$, $|\log_2\text{FC}| > 1.0$).
2. Maps significant proteins to functional macromolecular complexes.
3. Tests module over-representation by Fisher's exact test.
4. Computes mean complex $\log_2(\text{FC})$ to capture directional protein remodeling.

```{r multiomics-proteomics-modules-atoz, fig.width=8.5, fig.height=5.8}
# Step 1: Input LFQ protein intensity matrix across 6 biological replicates
set.seed(42)
proteins <- c(
  "FLG", "LOR", "IVL", "LCE3D", "SPRR2A",
  "DSC1", "DSG1", "DSP", "PKP1",
  "SPINK5", "SERPINB3", "SERPINB4",
  "S100A7", "S100A8", "S100A9", "DEFB4A",
  "ATP5F1A", "NDUFS1", "COX4I1", "SDHA",
  paste0("Protein_Background_", 1:150)
)
n_reps <- 6

lfq_hc <- matrix(rnorm(length(proteins) * n_reps, mean = 24, sd = 0.5), nrow = length(proteins))
lfq_ad <- matrix(rnorm(length(proteins) * n_reps, mean = 24, sd = 0.5), nrow = length(proteins))
rownames(lfq_hc) <- rownames(lfq_ad) <- proteins

# AD-specific protein shifts
lfq_ad[c("FLG", "LOR", "IVL", "LCE3D", "SPRR2A"), ] <- lfq_ad[c("FLG", "LOR", "IVL", "LCE3D", "SPRR2A"), ] - 2.5
lfq_ad[c("DSC1", "DSG1", "DSP", "PKP1"), ] <- lfq_ad[c("DSC1", "DSG1", "DSP", "PKP1"), ] - 1.8
lfq_ad[c("SPINK5", "SERPINB3", "SERPINB4"), ] <- lfq_ad[c("SPINK5", "SERPINB3", "SERPINB4"), ] + 2.4
lfq_ad[c("S100A7", "S100A8", "S100A9", "DEFB4A"), ] <- lfq_ad[c("S100A7", "S100A8", "S100A9", "DEFB4A"), ] + 3.2

# Step 2: Moderated statistical testing for differentially abundant proteins
de_prot <- do.call(rbind, lapply(seq_along(proteins), function(i) {
  tt <- t.test(lfq_ad[i, ], lfq_hc[i, ])
  data.frame(
    Protein = proteins[i],
    log2FC  = mean(lfq_ad[i, ]) - mean(lfq_hc[i, ]),
    pvalue  = tt$p.value,
    stringsAsFactors = FALSE

de_prot$padj <- p.adjust(de_prot$pvalue, method = "BH")

  "Cornified Envelope"          = c("FLG", "LOR", "IVL", "LCE3D", "SPRR2A"),

  "Antimicrobial Peptides"      = c("S100A7", "S100A8", "S100A9", "DEFB4A"),
  "Mitochondrial OxPhos"        = c("ATP5F1A", "NDUFS1", "COX4I1", "SDHA")
)

prot_ora <- cli_calc_ora(sig_prot, prot_modules, background = proteins)
prot_ora$MeanLog2FC <- vapply(prot_ora$Pathway, function(mod) {
  mean(de_prot$log2FC[de_prot$Protein %in% prot_modules[[mod]]])
}, numeric(1))

# Step 4: Compare across clinical phenotypes (AD vs HC and Psoriasis vs HC)
pso_shift <- c(-1.9, -1.4, 3.8, 1.8, 0.1)
prot_multi <- data.frame(
  Module   = rep(prot_ora$Pathway, 2),
  Contrast = rep(c("AD vs HC", "Psoriasis vs HC"), each = nrow(prot_ora)),
  Log2FC   = c(prot_ora$MeanLog2FC, pso_shift),
  negLogQ  = c(-log10(prot_ora$padj), c(4.8, 3.5, 9.2, 5.2, 0.2)),
  stringsAsFactors = FALSE
)

# Step 5: Render diverging bubble heatmap
clitheme("nature")

p_prot_mod <- cliplot(
  Module ~ Contrast,
  data       = prot_multi,
  by         = prot_multi$negLogQ,
  type       = type_bubble_diverging(
    palette      = "nature",
    midpoint     = 0,
    max_size     = 8.0,
    stroke_col   = "grey30",
    stroke_width = 0.4,
    size_name    = expression(-log[10]~italic(q)),
    fill_name    = expression(log[2]~"FC (Protein)")
  ),
  extra_data = list(fill = prot_multi$Log2FC),
  title      = "Mass Spectrometry Deep Proteomics Functional Module Enrichment",
  subtitle   = "Circle size encodes -log10 q; diverging fill encodes protein abundance log2(FC)"
)
p_prot_mod
```

### Cutaneous Microbiome Functional Metagenomics (MetaCyc Pathways): A to Z Pipeline

Shotgun metagenomics profiles metabolic pathway abundance across skin microenvironments. The pipeline:

1. Filters low-prevalence pathways (detected in $< 20\%$ of samples).
2. Stabilizes variance with $\log_2(\text{CPM} + 1)$ transformation.
3. Tests differential abundance between flare and remission with Wilcoxon rank-sum tests.
4. Corrects for multiple testing across pathways and anatomical microenvironments.

```{r multiomics-microbiome-metacyc-atoz, fig.width=8.5, fig.height=5.8}
# Step 1: Input MetaCyc functional pathway counts (CPM) across skin sites
set.seed(42)
metacyc_paths <- c(
  "Staphyloferrin Siderophore Biosynthesis",
  "Peptidoglycan Maturation",
  "Lipoteichoic Acid Biosynthesis",
  "SCFA (Butyrate) Production",
  "L-Arginine Degradation",
  "Bile Acid Hydrolysis"
)
sites <- c("Antecubital Fossa", "Volar Forearm", "Forehead")
n_subj <- 12

# Step 2 & 3: Differential testing (Flare vs Remission) per site
mb_results <- do.call(rbind, lapply(sites, function(st) {
  do.call(rbind, lapply(metacyc_paths, function(pwy) {
    flare_mean <- if (grepl("Staphyloferrin|Peptidoglycan|Lipoteichoic", pwy)) 5.2 else 2.1
    remis_mean <- if (grepl("Staphyloferrin|Peptidoglycan|Lipoteichoic", pwy)) 2.3 else 4.5
    
    flare_cpm <- pmax(0, rnorm(n_subj, mean = flare_mean, sd = 0.7))
    remis_cpm <- pmax(0, rnorm(n_subj, mean = remis_mean, sd = 0.7))
    
    wt <- wilcox.test(flare_cpm, remis_cpm)
    log2fc <- mean(flare_cpm) - mean(remis_cpm)
    prev <- mean(c(flare_cpm, remis_cpm) > 0.5) * 100
    
    data.frame(
      Pathway    = pwy,
      Site       = st,
      Log2FC     = log2fc,
      Prevalence = prev,
      pvalue     = wt$p.value,
      stringsAsFactors = FALSE
    )
  }))
}))

# Step 4: Adjust p-values across all tests
mb_results$padj    <- p.adjust(mb_results$pvalue, method = "BH")
mb_results$negLogQ <- -log10(mb_results$padj)

# Step 5: Render diverging bubble heatmap across anatomical microenvironments
clitheme("nature")

p_mb_metacyc <- cliplot(
  Pathway ~ Site,
  data       = mb_results,
  by         = mb_results$negLogQ,
  type       = type_bubble_diverging(
    palette      = "rdbu",
    midpoint     = 0,
    max_size     = 8.0,
    stroke_col   = "grey35",
    stroke_width = 0.35,

    fill_name    = expression(log[2]~"FC (Flare / Remission)")
  ),
  extra_data = list(fill = mb_results$Log2FC),
  title      = "Cutaneous Microbiome Functional Metagenomics (MetaCyc Pathways)",
  subtitle   = "Circle size encodes -log10 q; fill encodes flare vs remission log2(FC)"
)
```

## Bubble Heatmap Archetypes: `type = "bubble_heatmap"`

1. **Diamond Bubble Matrix**: classic diamond glyphs with alternating row bands.
2. **Circular Dot Bubble Matrix with Divergent Palette**: circular dots centered on zero to show positive and negative regulation.

4. **Square / Tile-Scaled Matrix**: proportional square glyphs in a tile grid.
5. **Directional Triangle Bubble Matrix**: oriented triangles indicating directional modulation across experimental cohorts.
