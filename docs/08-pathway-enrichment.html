8  Pathway Enrichment and Multi-Omics Abundance Profiles

  • Show All Code
  • Hide All Code
  • View Source

Pathway enrichment and multi-omics profiling aggregate molecular alterations into functional signatures. This chapter covers Gene Set Enrichment Analysis (GSEA) across multiple visualization modes, bubble heatmap archetypes across glyph shapes and color regimes, and rank-abundance dynamic range curves.

8.1 Gene Set Enrichment Analysis: type = "gsea" and type = "gsea_running"

Gene Set Enrichment Analysis (Subramanian et al., PNAS 2005) evaluates whether an a priori defined gene set S shows cumulative enrichment at the extremes of a ranked gene list L:

P_{\text{hit}}(S, i) = \sum_{g_j \in S, j \le i} \frac{|r_j|^p}{N_R}, \quad N_R = \sum_{g_j \in S} |r_j|^p

P_{\text{miss}}(S, i) = \sum_{g_j \notin S, j \le i} \frac{1}{N - N_H}

ES(S) = \arg\max_{i} |P_{\text{hit}}(S, i) - P_{\text{miss}}(S, i)|

cliomicplot provides four complementary visualizations for GSEA results: 1. Preranked Enrichment Dot Plot (type = "gsea"): Pathway terms ranked by effect magnitude, with dot size encoding -\log_{10}(\text{FDR}) and fill encoding Normalized Enrichment Score (NES). 2. Three-Tier Running Score Walk Plot (type = "gsea_running"): The classical GSEA profile displaying the cumulative walk curve, gene hit barcode rug, and ranked metric area. 3. Directional Diverging Lollipop Plot (type = "lollipop"): Horizontal effect size bars comparing positive and negative pathway activation. 4. Multi-Phenotype Comparison Matrix (type = type_bubble_diverging()): Cross-condition pathway activity across disease phenotypes and therapeutic stages.

8.1.1 Example 1: Preranked Pathway Enrichment Dot Plot

The dot plot displays top enriched pathways sorted by absolute NES, highlighting concurrent upregulation of inflammatory signaling and downregulation of lipid metabolism:

Show R code 
library(cliomicplot)
library(ggplot2)

pathways <- c(
  "Cytokine-Cytokine Receptor Interaction", "JAK-STAT Signaling Pathway",
  "Toll-like Receptor Signaling", "Th1 and Th2 Cell Differentiation",
  "Chemokine Signaling Pathway", "NF-kappa B Signaling",
  "IL-17 Signaling Pathway", "Antigen Processing and Presentation",
  "T Cell Receptor Signaling", "B Cell Receptor Signaling",
  "Natural Killer Cell Mediated Cytotoxicity", "Apoptosis",
  "Fatty Acid Metabolism", "Steroid Biosynthesis", "Keratinization"
)

gsea_df <- data.frame(
  Term = pathways,
  NES  = c(2.65, 2.38, 2.15, 2.08, 1.95, 1.88, 1.72, 1.65, 1.45, 1.25, 0.95, 0.82, -1.65, -1.98, -2.45),
  FDR  = c(1e-5, 2e-5, 8e-5, 1e-4, 3e-4, 5e-4, 1e-3, 2e-3, 5e-3, 0.015, 0.045, 0.082, 0.002, 0.0005, 0.0001)

clitheme("nature")

p_gsea <- cliplot(

  type     = "gsea",
  top_term = 15,
  title    = "Normalized Enrichment Scores Across Inflammatory Cascades"

8.1.2 Example 2: Three-Tier GSEA Running Enrichment Score Walk

The running enrichment score walk illustrates the cumulative enrichment score ES(i) across ranked genes, identifying the leading-edge subset that accounts for peak enrichment:

Show R code 
set.seed(42)

# Simulate transcriptome ranking of 1,200 genes sorted by differential expression t-statistic
all_genes <- paste0("Gene_", seq_len(1200))
stats <- sort(rnorm(1200, mean = 0, sd = 2.0), decreasing = TRUE)
names(stats) <- all_genes

# Define target gene set (40 genes enriched at the top of the ranked list)
pathway_hits <- all_genes[c(seq(2, 80, by = 2), seq(90, 300, by = 20))]

# Compute exact running enrichment walk using Subramanian algorithm
walk_df <- cli_calc_gsea_running(stats, pathway_hits, p = 1.0)

# Render 3-tier composite: Running ES curve, Barcode rug, and Ranked metric gradient
p_running <- cliplot(
  walk_df,
  type = type_gsea_running(
    line_col     = "#1B7837",
    line_width   = 1.1,
    barcode_col  = "#182033",
    show_metric  = TRUE,
    peak_color   = "#D73027",
    pathway_name = "Hallmark IL-4 / IL-13 Signaling Pathway",
    nes          = 2.45,
    fdr          = 0.0001
  )
)
p_running

8.1.3 Example 3: Directional Diverging Lollipop Enrichment Plot

Horizontal lollipops provide a clean visualization of pathway activation versus repression relative to the zero null baseline:

Show R code 
pathway_subset <- c(
  "Cytokine-Cytokine Receptor", "JAK-STAT Cascade", "Th2 Differentiation",
  "Chemokine Cascade", "NF-kB Activation", "IL-17 Signaling",
  "Fatty Acid Metabolism", "Keratinization", "Steroid Biosynthesis"

nes_subset <- c(2.65, 2.38, 2.08, 1.95, 1.88, 1.72, -1.65, -1.98, -2.45)

lollipop_df <- data.frame(
  Term = pathway_subset,
  NES  = nes_subset,
  stringsAsFactors = FALSE
)

clitheme("science")

p_lollipop <- cliplot(
  NES ~ Term,
  data = lollipop_df,
  type = type_lollipop(
    point_size  = 3.8,
    stem_width  = 0.8,
    point_color = "#3B4992"
  ),
  title = "Directional Pathway Enrichment Relative to Zero Baseline",
  xlab  = "Normalized Enrichment Score (NES)"
) +
  ggplot2::geom_vline(xintercept = 0, linetype = "dashed", color = "grey50", linewidth = 0.4)
p_lollipop

8.2 Bubble Heatmap Archetypes: type = "bubble_heatmap"

Bubble heatmaps display two continuous variables across features (rows) and conditions (columns). Point size encodes magnitude, count, or significance; fill colour encodes directional effect size (\log_2\text{FC}, NES) or continuous significance (-\log_{10}P).

cliomicplot provides five bubble forms: 1. Diamond Bubble Matrix: classic diamond glyphs with alternating row bands. 2. Circular Dot Bubble Matrix with Divergent Palette: circular dots centered on zero to show positive and negative regulation. 3. Significance-Glyph Annotated Matrix: bubbles with significance asterisks (*, **, ***) based on adjusted P-values. 4. Square / Tile-Scaled Matrix: proportional square glyphs in a tile grid. 5. Directional Triangle Bubble Matrix: oriented triangles indicating directional modulation across experimental cohorts.

8.2.1 Form 1: Classic Diamond Bubble Matrix

Diamond bubble matrices display effect magnitude as diamond area and statistical significance as fill colour. Values exceeding label_threshold are labelled directly inside the glyphs.

Show R code 
set.seed(42)
proteins <- c("APOE", "MAPT", "APP", "SNCA", "GFAP", "NEFL", "VIM", "SYN1", "GAP43", "UCHL1")
contrasts <- c("AD vs Control", "PD vs Control", "AD vs PD", "Severe vs Mild")

bh_df <- expand.grid(Protein = proteins, Comparison = contrasts, stringsAsFactors = FALSE)
bh_df$absFC <- runif(nrow(bh_df), 0.2, 3.5)
bh_df$negLogP <- runif(nrow(bh_df), 1.0, 15.0)

clitheme("cell")

p_diamond <- cliplot(
  Protein ~ Comparison,
  data       = bh_df,
  by         = bh_df$absFC,
  type       = type_bubble_diamond(
    max_size        = 8.0,
    size_name       = "|log2FC|",
    fill_name       = expression(-log[10]~P),
    fill_low        = "#4575B4",
    fill_mid        = "#FFFFBF",
    fill_high       = "#D73027"
  ),
  extra_data = list(fill = bh_df$negLogP),
  title      = "Diamond Bubble Matrix: Neurodegenerative Biomarkers",
  subtitle   = "Point size reflects |log2FC|; colour gradient reflects -log10 P"
)
p_diamond

Pathway enrichment and multi-omics profiling aggregate molecular alterations into functional signatures. ## Gene Set Enrichment Analysis: `type = "gsea"` and `type = "gsea_running"`

Gene Set Enrichment Analysis (Subramanian et al., *PNAS* 2005) evaluates whether an a priori defined gene set $S$ shows cumulative enrichment at the extremes of a ranked gene list $L$:

$$P_{\text{hit}}(S, i) = \sum_{g_j \in S, j \le i} \frac{|r_j|^p}{N_R}, \quad N_R = \sum_{g_j \in S} |r_j|^p$$

$$P_{\text{miss}}(S, i) = \sum_{g_j \notin S, j \le i} \frac{1}{N - N_H}$$

$$ES(S) = \arg\max_{i} |P_{\text{hit}}(S, i) - P_{\text{miss}}(S, i)|$$

`cliomicplot` provides four complementary visualizations for GSEA results:
1. **Preranked Enrichment Dot Plot (`type = "gsea"`)**: Pathway terms ranked by effect magnitude, with dot size encoding $-\log_{10}(\text{FDR})$ and fill encoding Normalized Enrichment Score (NES).
2. **Three-Tier Running Score Walk Plot (`type = "gsea_running"`)**: The classical GSEA profile displaying the cumulative walk curve, gene hit barcode rug, and ranked metric area.
3. **Directional Diverging Lollipop Plot (`type = "lollipop"`)**: Horizontal effect size bars comparing positive and negative pathway activation.
4. **Multi-Phenotype Comparison Matrix (`type = type_bubble_diverging()`)**: Cross-condition pathway activity across disease phenotypes and therapeutic stages.

## Bubble Heatmap Archetypes: `type = "bubble_heatmap"`

Bubble heatmaps display two continuous variables across features (rows) and conditions (columns). Point size encodes magnitude, count, or significance; fill colour encodes directional effect size ($\log_2\text{FC}$, NES) or continuous significance ($-\log_{10}P$).

`cliomicplot` provides five bubble forms:
1. **Diamond Bubble Matrix**: classic diamond glyphs with alternating row bands.
2. **Circular Dot Bubble Matrix with Divergent Palette**: circular dots centered on zero to show positive and negative regulation.
3. **Significance-Glyph Annotated Matrix**: bubbles with significance asterisks (`*`, `**`, `***`) based on adjusted $P$-values.
4. **Square / Tile-Scaled Matrix**: proportional square glyphs in a tile grid.
5. **Directional Triangle Bubble Matrix**: oriented triangles indicating directional modulation across experimental cohorts.

### Form 1: Classic Diamond Bubble Matrix

Diamond bubble matrices display effect magnitude as diamond area and statistical significance as fill colour. Values exceeding `label_threshold` are labelled directly inside the glyphs.

```{r bubble-diamond-demo, fig.width=8.5, fig.height=6.2}
set.seed(42)

bh_df$absFC <- runif(nrow(bh_df), 0.2, 3.5)
bh_df$negLogP <- runif(nrow(bh_df), 1.0, 15.0)

clitheme("cell")

  Protein ~ Comparison,
  data       = bh_df,
  by         = bh_df$absFC,
  type       = type_bubble_diamond(
    max_size        = 8.0,
    size_name       = "|log2FC|",
    fill_name       = expression(-log[10]~P),
    fill_low        = "#4575B4",
    fill_mid        = "#FFFFBF",
    fill_high       = "#D73027"
  ),
  extra_data = list(fill = bh_df$negLogP),
  title      = "Diamond Bubble Matrix: Neurodegenerative Biomarkers",
  subtitle   = "Point size reflects |log2FC|; colour gradient reflects -log10 P"
)
p_diamond
```
