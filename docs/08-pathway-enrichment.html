Pathway enrichment and multi-omics profiling aggregate molecular alterations into functional signatures. This chapter covers Gene Set Enrichment Analysis (GSEA), bubble heatmap archetypes across glyph shapes and color regimes, and rank-abundance dynamic range curves.

8.1 Gene Set Enrichment Analysis: type = "gsea"

Gene Set Enrichment Analysis (Subramanian et al., PNAS 2005) evaluates whether an a priori defined gene set S shows cumulative enrichment at the extremes of a ranked gene list L:

P_{\text{hit}}(S, i) = \sum_{g_j \in S, j \le i} \frac{|r_j|^p}{N_R}, \quad N_R = \sum_{g_j \in S} |r_j|^p

P_{\text{miss}}(S, i) = \sum_{g_j \notin S, j \le i} \frac{1}{N - N_H}

ES(S) = \arg\max_{i} |P_{\text{hit}}(S, i) - P_{\text{miss}}(S, i)|

Show R code 
library(cliomicplot)
library(ggplot2)

pathways <- c(
  "Cytokine-Cytokine Receptor Interaction", "JAK-STAT Signaling Pathway",
  "Toll-like Receptor Signaling", "Th1 and Th2 Cell Differentiation",
  "Chemokine Signaling Pathway", "NF-kappa B Signaling",
  "IL-17 Signaling Pathway", "Antigen Processing and Presentation",
  "T Cell Receptor Signaling", "B Cell Receptor Signaling",
  "Natural Killer Cell Mediated Cytotoxicity", "Apoptosis",
  "Fatty Acid Metabolism", "Steroid Biosynthesis", "Keratinization"
)

gsea_df <- data.frame(
  Term = pathways,
  NES  = c(2.65, 2.38, 2.15, 2.08, 1.95, 1.88, 1.72, 1.65, 1.45, 1.25, 0.95, 0.82, -1.65, -1.98, -2.45),
  FDR  = c(1e-5, 2e-5, 8e-5, 1e-4, 3e-4, 5e-4, 1e-3, 2e-3, 5e-3, 0.015, 0.045, 0.082, 0.002, 0.0005, 0.0001)
)

clitheme("nature")

p_gsea <- cliplot(
  gsea_df,
  type     = "gsea",
  top_term = 15,
  title    = "Normalized Enrichment Scores Across Inflammatory Cascades"
)
p_gsea

8.2 Bubble Heatmap Archetypes: type = "bubble_heatmap"

Bubble heatmaps display two continuous variables across features (rows) and conditions (columns). Point size encodes magnitude, count, or significance; fill colour encodes directional effect size (\log_2\text{FC}, NES) or continuous significance (-\log_{10}P).

cliomicplot provides five bubble forms: 1. Diamond Bubble Matrix: classic diamond glyphs with alternating row bands. 2. Circular Dot Bubble Matrix with Divergent Palette: circular dots centered on zero to show positive and negative regulation. 3. Significance-Glyph Annotated Matrix: bubbles with significance asterisks (*, **, ***) based on adjusted P-values. 4. Square / Tile-Scaled Matrix: proportional square glyphs in a tile grid. 5. Directional Triangle Bubble Matrix: oriented triangles indicating directional modulation across experimental cohorts.

8.2.1 Form 1: Classic Diamond Bubble Matrix

Diamond bubble matrices display effect magnitude as diamond area and statistical significance as fill colour. Values exceeding label_threshold are labelled directly inside the glyphs.

Show R code 
set.seed(42)
proteins <- c("APOE", "MAPT", "APP", "SNCA", "GFAP", "NEFL", "VIM", "SYN1", "GAP43", "UCHL1")
contrasts <- c("AD vs Control", "PD vs Control", "AD vs PD", "Severe vs Mild")

bh_df <- expand.grid(Protein = proteins, Comparison = contrasts, stringsAsFactors = FALSE)
bh_df$absFC <- runif(nrow(bh_df), 0.2, 3.5)
bh_df$negLogP <- runif(nrow(bh_df), 1.0, 15.0)

clitheme("cell")

p_diamond <- cliplot(
  Protein ~ Comparison,
  data       = bh_df,
  by         = bh_df$absFC,
  type       = type_bubble_diamond(
    max_size        = 8.0,
    size_name       = "|log2FC|",
    fill_name       = expression(-log[10]~P),
    fill_low        = "#4575B4",
    fill_mid        = "#FFFFBF",
    fill_high       = "#D73027"
  ),
  extra_data = list(fill = bh_df$negLogP),
  title      = "Diamond Bubble Matrix: Neurodegenerative Biomarkers",
  subtitle   = "Point size reflects |log2FC|; colour gradient reflects -log10 P"
)
p_diamond

8.2.2 Form 2: Circular Dot Bubble Matrix with Divergent Palette

For bidirectional metrics such as Normalized Enrichment Scores (NES) or signed \log_2\text{FC}, type_bubble_diverging() applies a diverging colour gradient centered at 0 (e.g. palette = "nature": navy to white to red). Bubble radius represents -\log_{10}q.

Show R code 
set.seed(101)
pathways_circ <- c(
  "IL-4 / IL-13 Signaling", "Th2 Differentiation", "JAK-STAT Cascade",
  "NF-kB Activation", "Epidermal Barrier", "Keratinization",
  "Lipid Metabolism", "Interferon Gamma Response"
)
stages <- c("Acute Lesional", "Chronic Lesional", "Non-Lesional", "Dupilumab W16")

da_df <- expand.grid(Pathway = pathways_circ, Stage = stages, stringsAsFactors = FALSE)
da_df$NES <- c(
  2.4, 2.8, 0.4, -1.8,
  2.1, 2.5, 0.2, -1.5,
  1.8, 2.2, 0.5, -1.2,
  1.9, 1.7, 0.3, -0.9,
  -2.2, -2.6, -0.3, 1.9,
  -2.5, -3.1, -0.5, 2.2,
  -1.7, -2.1, -0.2, 1.4,
  0.6, 1.2, 0.1, -0.4
)
da_df$negLogQ <- runif(nrow(da_df), 1.5, 12.0)

clitheme("nature")

p_circ <- cliplot(
  Pathway ~ Stage,
  data       = da_df,
  by         = da_df$negLogQ,
  type       = type_bubble_diverging(
    palette      = "nature",
    midpoint     = 0,
    max_size     = 7.5,
    stroke_col   = "grey30",
    stroke_width = 0.35,
    size_name    = expression(-log[10]~italic(q)),
    fill_name    = "NES"
  ),
  extra_data = list(fill = da_df$NES),
  title      = "Inflammatory Pathway Modulation Across Disease Stages",
  subtitle   = "Circle size encodes -log10 q; diverging fill encodes Normalized Enrichment Score"
)
p_circ

8.3 Rank-Abundance Dynamic Range Curves: type = "rankabundance"

In quantitative proteomics, rank-abundance curves visualize the dynamic range of protein detection across orders of magnitude:

Show R code 
set.seed(42)
n_prot <- 800
intensities <- sort(10^rnorm(n_prot, mean = 6.5, sd = 1.1), decreasing = TRUE)
ranks <- seq_len(n_prot)

rank_df <- data.frame(
  Rank      = ranks,
  Intensity = intensities,
  Protein   = paste0("Prot_", ranks)
)

clitheme("science")

p_rank <- cliplot(
  Intensity ~ Rank,
  data = rank_df,
  type = type_rankabundance(
    log_scale     = "10",
    point_color   = "#4DBBD5",
    marginal_type = "density",
    label_genes   = c("Prot_1", "Prot_10", "Prot_50", "Prot_200"),
    label_color   = "#E64B35",
    label_size    = 3.0
  ),
  title    = "Dynamic Range of Proteome Detection",
  subtitle = "Protein abundance spanning ~5 orders of magnitude with marginal density",
  xlab     = "Abundance Rank",
  ylab     = "LFQ Intensity"
)
p_rank

## Rank-Abundance Dynamic Range Curves: `type = "rankabundance"`

In quantitative proteomics, rank-abundance curves visualize the dynamic range of protein detection across orders of magnitude:

```{r rank-abundance-demo, fig.width=8.0, fig.height=5.0}
set.seed(42)
n_prot <- 800
intensities <- sort(10^rnorm(n_prot, mean = 6.5, sd = 1.1), decreasing = TRUE)
ranks <- seq_len(n_prot)

rank_df <- data.frame(
  Rank      = ranks,
  Intensity = intensities,
  Protein   = paste0("Prot_", ranks)
)

clitheme("science")

p_rank <- cliplot(
  Intensity ~ Rank,
  data = rank_df,
  type = type_rankabundance(
    log_scale     = "10",
    point_color   = "#4DBBD5",
    marginal_type = "density",
    label_genes   = c("Prot_1", "Prot_10", "Prot_50", "Prot_200"),
    label_color   = "#E64B35",
    label_size    = 3.0
  ),
  title    = "Dynamic Range of Proteome Detection",
  subtitle = "Protein abundance spanning ~5 orders of magnitude with marginal density",
  xlab     = "Abundance Rank",
  ylab     = "LFQ Intensity"
)
p_rank
```
