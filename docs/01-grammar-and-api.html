cliplot() provides a single entry point for generating biomedical visualizations through a formula syntax. This chapter details the formula grammar, the parameter system (clipar), and the type dispatch architecture.

1.1 Formula Syntax

cliplot() accepts standard R formulas mapping variables to visual roles:

  • y ~ x: Bivariate plots (boxplots, scatter plots, violin plots, ROC curves).
  • y ~ x | facet: Conditioned plots faceted across biological subgroups or clinical trial cohorts.
  • Surv(time, event) ~ arm: Time-to-event outcomes with survival curves, risk tables, and hazard ratios.
  • ~ x: Univariate distributions (histograms, density estimates, rank-abundance curves).
# General syntax
p <- cliplot(
  formula = Value ~ Biomarker,
  data    = clinical_data,
  type    = "boxplot",
  preset  = "nature"
)

1.2 Function Dispatch and Plot Types

The type argument selects the geometry and statistical layer. It accepts either character aliases or typed constructor functions:

Show R code 
library(cliomicplot)
library(ggplot2)

# Generate reproducible clinical cohort
set.seed(42)
df_cohort <- data.frame(
  Biomarker  = factor(rep(c("Control", "Mild_AD", "Severe_AD"), each = 40),
                      levels = c("Control", "Mild_AD", "Severe_AD")),
  Treatment  = factor(rep(rep(c("Placebo", "Biologic"), each = 20), 3),
                      levels = c("Placebo", "Biologic")),
  Age_Group  = factor(rep(c("Pediatric", "Adult"), 60)),
  IL13_pg_ml = c(
    rnorm(20, 5.2, 0.9), rnorm(20, 3.8, 0.8),
    rnorm(20, 10.5, 1.4), rnorm(20, 7.2, 1.2),
    rnorm(20, 18.2, 2.1), rnorm(20, 11.5, 1.8)
  )
)

# Direct character specification
p_box <- cliplot(
  IL13_pg_ml ~ Biomarker,
  data   = df_cohort,
  type   = "boxplot",
  preset = "nature",
  title  = "Serum IL-13 by Clinical Severity"

1.4 Advanced Distribution Architectures: Split Violins and Rainclouds

cliomicplot provides specialized distribution types for multi-arm clinical trials and single-cell cohorts.

1.4.1 Dual-Condition Contrast: type_split_violin()

When comparing two treatment arms (Placebo vs. Biologic) across multiple severity tiers, type_split_violin() renders both distributions back-to-back along a shared category spine. Each condition is highlighted by group color, with inner boxplots dodged inside each split half. Adding stat.test = "t.test" performs within-tier comparisons with horizontal bracket bars:

p_split <- cliplot(

    scale     = "width"

  palette   = "jco",
  theme     = "scifig",
  stat.test = "t.test",
  title     = "IL-13 Modulation Under Biologic vs. Placebo Across Severity Tiers",
  subtitle  = "Split-half comparison with within-tier two-sample t-test",
  ylab      = "Serum IL-13 (pg/mL)",
  xlab      = "Biomarker Severity Tier"

1.5 Nature Aging Pathology Boxplots: type_pathology_boxplot()

type_pathology_boxplot() implements the Nature Aging and SciFig boxplot standard established in Yadav et al. 2026. Designed for large-cohort clinical and multi-tissue omics contrasts (such as GTEx donors stratified by microscopic pathology findings), it incorporates seven publication elements:

  1. Category-matched colored outlines: Box outlines and whiskers match the group palette (#0F4D92 vs. #D55E00), while box interiors retain low-alpha fill (alpha = 0.22).
  2. Bold black median bar: An explicit #111111 horizontal crossbar (linewidth = 0.85) highlights the sample median without obscuring point distributions.
  3. Paired mean connecting lines: Dotted trajectories connect group means across conditions within each category, showing effect direction.
  4. Mean diamond glyphs: A white-filled diamond marker (shape = 23) displays the arithmetic mean.
  5. Dashed zero baseline: A horizontal reference line (y = 0) renders behind all distributions.
  6. Subsampled jitter: jitter_subsample downsamples massive background groups (e.g. N \approx 20\text{k}) to prevent overplotting while keeping box statistics computed on all observations.
  7. Mathematical significance brackets: stat.label = "p.nature" renders two-line significance annotations with exact Unicode scientific exponents (***\text{ (P = }1.7 \times 10^{-9}\text{)} or \text{n.s. (P = 0.55)}).
Show R code 
# Simulate multi-tissue pathology data
set.seed(42)
pathology_df <- data.frame(
  feature = factor(rep(c("Calcification\n(n = 225)", "Fibrosis\n(n = 531)", "Atrophy\n(n = 301)"), each = 80)),
  status  = factor(rep(c("Absent (~20k)", "Present"), each = 40, times = 3), levels = c("Absent (~20k)", "Present")),
  delta   = c(
    rnorm(40, mean = 0.10, sd = 0.07), rnorm(40, mean = 0.13, sd = 0.08),
    rnorm(40, mean = 0.13, sd = 0.08), rnorm(40, mean = 0.16, sd = 0.09),
    rnorm(40, mean = 0.13, sd = 0.08), rnorm(40, mean = 0.14, sd = 0.14)
  )
)

p_pathology <- cliplot(
  delta ~ feature | status,
  data       = pathology_df,
  type       = type_pathology_boxplot(
    width            = 0.30,
    position_dodge   = 0.42,
    alpha            = 0.22,
    linewidth        = 0.45,
    jitter_subsample = 40,
    jitter_size      = 0.85,
    jitter_alpha     = 0.35,
    mean_size        = 1.8,
    bold_median_lwd  = 0.85
  ),
  palette    = "pathology",
  theme      = "pathology",
  stat.test  = "t.test",
  stat.label = "p.nature",
  stat.y     = c(0.38, 0.42, 0.48),
  title      = "Structural Aging Across Microscopic Pathology Findings",
  subtitle   = "Nature Aging boxplot architecture with paired mean trajectory lines",
  xlab       = "Microscopic Pathology Finding",
  ylab       = "Structural Aging Δ Score"
)
p_pathology

1.6 Ecology & Demographic Viability Rainclouds: type_ecology_raincloud()

In ecology, evolutionary demographics, and population viability analyses, distributions are often visualized using half-boxed raincloud composites. type_ecology_raincloud() (alias type_half_boxed()) implements this architecture with six components:

  1. White-filled boxplot with colored outline: A vertical boxplot nudged to the left (box_nudge = -0.15, width = 0.17) with solid white fill (#FFFFFF), thick category-colored borders (linewidth = 1.1), and open square outlier markers (shape = 0, size = 2.0).
  2. Central mean dot: A solid circular marker (shape = 16, size = 3.8) positioned directly between the boxplot and the violin density.
  3. Right-facing half-violin density: A density slab (ggdist::stat_halfeye or base R fallback) extending rightward from a flat vertical spine.
  4. Reference baseline: A dashed horizontal line (e.g. ref_line = 1.0 representing demographic population replacement equilibrium \lambda = 1.0).
  5. Mean and 95% CI text annotation: Automated Student’s t 95% Confidence Interval calculation rendered directly below each category: \lambda = \bar{y}, \quad (95\%\text{ CI: } \bar{y} \pm t_{n-1, 0.975} \times \text{SE})
  6. Ecology theme: theme = "ecology" establishes a 4-sided rectangular border, clean white interior, outward ticks, and bold axis typography.
Show R code 
# Simulate reseeding viability data (population growth rate lambda across years)
set.seed(42)
n_reps <- 250
y_2yr  <- rnorm(n_reps, mean = 0.869, sd = 0.055)
y_5yr  <- rnorm(n_reps, mean = 0.713, sd = 0.042)
y_10yr <- rnorm(n_reps, mean = 0.727, sd = 0.045)
# Add outlier replicates matching open square glyphs
y_2yr[1:4]  <- c(1.03, 1.05, 0.72, 0.71)
y_5yr[1:3]  <- c(0.85, 0.60, 0.59)
y_10yr[1:3] <- c(0.86, 0.84, 0.60)

reseeding_df <- data.frame(
  years = factor(rep(c("2 yr", "5 yr", "10 yr"), each = n_reps), levels = c("2 yr", "5 yr", "10 yr")),
  growth_rate = c(y_2yr, y_5yr, y_10yr)
)

p_ecology <- cliplot(
  growth_rate ~ years,
  data       = reseeding_df,
  type       = type_ecology_raincloud(
    ref_line       = 1.0,
    show_stats     = TRUE,
    stat_param     = "\u03bb",
    stat_digits    = 3,
    stat_y_pos     = 0.52
  ),
  palette    = "ecology",
  theme      = "ecology",
  xlab       = "Reseeding years",
  ylab       = expression(paste("population growth rate (", lambda, ")"))
) +
  ggplot2::scale_y_continuous(
    limits = c(0.48, 1.11),
    breaks = seq(0.5, 1.1, by = 0.1)
  )
p_ecology

1.7 Transparent Data Distribution: Scatter-Box-Violin Plots (David Baranger Style)

A recognized issue in biomedical and behavioral data visualization is the over-reliance on bar plots with standard error bars (“dynamite plungers”), which obscure sample sizes, bimodal clusters, skewness, and outliers. In “Showing your data: Scatter, box, & violin plots” (2018), David Baranger advocates layering three complementary representations of the data:

  1. Background Kernel Density (geom_violin): Shows the overall probability density and distribution shape (alpha = 0.30, scale = "width", linewidth = 0.55).
  2. Foreground Notched Boxplot (geom_boxplot): A narrow summary structure (width = 0.22, alpha = 0.75) with black borders and notches indicating the 95% confidence interval of the median (1.58 \times \text{IQR} / \sqrt{n}). Outliers are hidden (outlier.shape = NA) to eliminate duplicate points.
  3. Overlaid Raw Data Points (geom_jitter / geom_point): Individual observations displayed with black borders (shape = 21, stroke = 0.35, size = 1.8, alpha = 0.65) and fill colors matching the treatment category, ensuring complete transparency.

cliomicplot provides type_scatter_box_violin() (aliases: type_baranger(), type_sbv(), and type_boxplot(style = "baranger")), as well as two-component variants type_scatter_box() and type_box_violin().

1.7.1 Single-Factor Demonstration

Show R code 
p_sbv_single <- cliplot(
  Sepal.Length ~ Species,
  data     = iris,
  type     = type_scatter_box_violin(notch = TRUE),
  palette  = "nature",
  theme    = "nature",
  title    = "Fisher Iris Sepal Length Distribution",
  subtitle = "David Baranger scatter-box-violin architecture with 95% median CI notches",
  ylab     = "Sepal Length (cm)",
  xlab     = "Iris Species"
)
p_sbv_single

# Graphic Grammar and Core API

`cliplot()` provides a single entry point for generating biomedical visualizations through a formula syntax. This chapter details the formula grammar, the parameter system (`clipar`), and the type dispatch architecture.

## Formula Syntax

`cliplot()` accepts standard R formulas mapping variables to visual roles:

- `y ~ x`: Bivariate plots (boxplots, scatter plots, violin plots, ROC curves).
- `y ~ x | facet`: Conditioned plots faceted across biological subgroups or clinical trial cohorts.
- `Surv(time, event) ~ arm`: Time-to-event outcomes with survival curves, risk tables, and hazard ratios.
- `~ x`: Univariate distributions (histograms, density estimates, rank-abundance curves).

```r
# General syntax
p <- cliplot(
  formula = Value ~ Biomarker,
  data    = clinical_data,
  type    = "boxplot",
  preset  = "nature"
)
```

## Nature Aging Pathology Boxplots: `type_pathology_boxplot()`

`type_pathology_boxplot()` implements the Nature Aging and SciFig boxplot standard established in Yadav et al. 2026. Designed for large-cohort clinical and multi-tissue omics contrasts (such as GTEx donors stratified by microscopic pathology findings), it incorporates seven publication elements:

1. **Category-matched colored outlines**: Box outlines and whiskers match the group palette (`#0F4D92` vs. `#D55E00`), while box interiors retain low-alpha fill (`alpha = 0.22`).
2. **Bold black median bar**: An explicit `#111111` horizontal crossbar (`linewidth = 0.85`) highlights the sample median without obscuring point distributions.
3. **Paired mean connecting lines**: Dotted trajectories connect group means across conditions within each category, showing effect direction.
4. **Mean diamond glyphs**: A white-filled diamond marker (`shape = 23`) displays the arithmetic mean.
5. **Dashed zero baseline**: A horizontal reference line (`y = 0`) renders behind all distributions.
6. **Subsampled jitter**: `jitter_subsample` downsamples massive background groups (e.g. $N \approx 20\text{k}$) to prevent overplotting while keeping box statistics computed on all observations.
7. **Mathematical significance brackets**: `stat.label = "p.nature"` renders two-line significance annotations with exact Unicode scientific exponents ($***\text{ (P = }1.7 \times 10^{-9}\text{)}$ or $\text{n.s. (P = 0.55)}$).

```{r pathology-boxplot-demo, fig.width=7.5, fig.height=5.2}
# Simulate multi-tissue pathology data
```

## Ecology & Demographic Viability Rainclouds: `type_ecology_raincloud()`

In ecology, evolutionary demographics, and population viability analyses, distributions are often visualized using half-boxed raincloud composites. `type_ecology_raincloud()` (alias `type_half_boxed()`) implements this architecture with six components:

1. **White-filled boxplot with colored outline**: A vertical boxplot nudged to the left (`box_nudge = -0.15`, `width = 0.17`) with solid white fill (`#FFFFFF`), thick category-colored borders (`linewidth = 1.1`), and open square outlier markers (`shape = 0`, `size = 2.0`).
2. **Central mean dot**: A solid circular marker (`shape = 16`, `size = 3.8`) positioned directly between the boxplot and the violin density.
3. **Right-facing half-violin density**: A density slab (`ggdist::stat_halfeye` or base R fallback) extending rightward from a flat vertical spine.
4. **Reference baseline**: A dashed horizontal line (e.g. `ref_line = 1.0` representing demographic population replacement equilibrium $\lambda = 1.0$).
5. **Mean and 95% CI text annotation**: Automated Student's $t$ 95% Confidence Interval calculation rendered directly below each category:
   $$\lambda = \bar{y}, \quad (95\%\text{ CI: } \bar{y} \pm t_{n-1, 0.975} \times \text{SE})$$
6. **Ecology theme**: `theme = "ecology"` establishes a 4-sided rectangular border, clean white interior, outward ticks, and bold axis typography.

```{r ecology-raincloud-demo, fig.width=7.5, fig.height=5.4}
# Simulate reseeding viability data (population growth rate lambda across years)

y_2yr  <- rnorm(n_reps, mean = 0.869, sd = 0.055)

y_10yr <- rnorm(n_reps, mean = 0.727, sd = 0.045)

  years = factor(rep(c("2 yr", "5 yr", "10 yr"), each = n_reps), levels = c("2 yr", "5 yr", "10 yr")),
  growth_rate = c(y_2yr, y_5yr, y_10yr)

p_ecology <- cliplot(
  growth_rate ~ years,
  data       = reseeding_df,
  type       = type_ecology_raincloud(
    ref_line       = 1.0,
    show_stats     = TRUE,

  ggplot2::scale_y_continuous(
    limits = c(0.48, 1.11),
```

## Transparent Data Distribution: Scatter-Box-Violin Plots (David Baranger Style)

A recognized issue in biomedical and behavioral data visualization is the over-reliance on bar plots with standard error bars ("dynamite plungers"), which obscure sample sizes, bimodal clusters, skewness, and outliers. In *"Showing your data: Scatter, box, & violin plots"* (2018), David Baranger advocates layering three complementary representations of the data:

1. **Background Kernel Density (`geom_violin`)**: Shows the overall probability density and distribution shape (`alpha = 0.30`, `scale = "width"`, `linewidth = 0.55`).
2. **Foreground Notched Boxplot (`geom_boxplot`)**: A narrow summary structure (`width = 0.22`, `alpha = 0.75`) with black borders and notches indicating the 95% confidence interval of the median ($1.58 \times \text{IQR} / \sqrt{n}$). Outliers are hidden (`outlier.shape = NA`) to eliminate duplicate points.
3. **Overlaid Raw Data Points (`geom_jitter` / `geom_point`)**: Individual observations displayed with black borders (`shape = 21`, `stroke = 0.35`, `size = 1.8`, `alpha = 0.65`) and fill colors matching the treatment category, ensuring complete transparency.

`cliomicplot` provides `type_scatter_box_violin()` (aliases: `type_baranger()`, `type_sbv()`, and `type_boxplot(style = "baranger")`), as well as two-component variants `type_scatter_box()` and `type_box_violin()`.

### Single-Factor Demonstration

```{r baranger-single-demo, fig.width=7.2, fig.height=5.0}
p_sbv_single <- cliplot(
  Sepal.Length ~ Species,
  data     = iris,
  type     = type_scatter_box_violin(notch = TRUE),
  palette  = "nature",
  theme    = "nature",
  title    = "Fisher Iris Sepal Length Distribution",
  subtitle = "David Baranger scatter-box-violin architecture with 95% median CI notches",
  ylab     = "Sepal Length (cm)",
  xlab     = "Iris Species"
)
```
