cliplot() provides a single entry point for generating biomedical visualizations through a formula syntax. This chapter details the formula grammar, the parameter system (clipar), and the type dispatch architecture.

1.1 Formula Syntax

cliplot() accepts standard R formulas mapping variables to visual roles:

  • y ~ x: Bivariate plots (boxplots, scatter plots, violin plots, ROC curves).
  • y ~ x | facet: Conditioned plots faceted across biological subgroups or clinical trial cohorts.
  • Surv(time, event) ~ arm: Time-to-event outcomes with survival curves, risk tables, and hazard ratios.
  • ~ x: Univariate distributions (histograms, density estimates, rank-abundance curves).
# General syntax
p <- cliplot(
  formula = Value ~ Biomarker,
  data    = clinical_data,
  type    = "boxplot",
  preset  = "nature"
)

1.2 Function Dispatch and Plot Types

The type argument selects the geometry and statistical layer. It accepts either character aliases or typed constructor functions:

Code 
library(cliomicplot)
library(ggplot2)

# Generate reproducible clinical cohort
set.seed(42)
df_cohort <- data.frame(
  Biomarker  = factor(rep(c("Control", "Mild_AD", "Severe_AD"), each = 40),
                      levels = c("Control", "Mild_AD", "Severe_AD")),
  Treatment  = factor(rep(rep(c("Placebo", "Biologic"), each = 20), 3),
                      levels = c("Placebo", "Biologic")),
  Age_Group  = factor(rep(c("Pediatric", "Adult"), 60)),
  IL13_pg_ml = c(
    rnorm(20, 5.2, 0.9), rnorm(20, 3.8, 0.8),
    rnorm(20, 10.5, 1.4), rnorm(20, 7.2, 1.2),
    rnorm(20, 18.2, 2.1), rnorm(20, 11.5, 1.8)
  )
)

# Direct character specification
p_box <- cliplot(
  IL13_pg_ml ~ Biomarker,
  data   = df_cohort,
  type   = "boxplot",
  preset = "nature",
  title  = "Serum IL-13 by Clinical Severity"
)
p_box

1.2.1 Typed Constructor Functions

Constructor functions configure geometry-specific options with autocomplete support:

Code 
p_viol <- cliplot(
  IL13_pg_ml ~ Biomarker,
  data  = df_cohort,
  type  = type_violin(inner = "boxplot", trim = FALSE),
  theme = "lancet"
)
p_viol

1.3 The 4-Step Progressive Pipeline: Basic, Color, Template, and Statistics

Scientific figures in cliomicplot are constructed through a four-step layered workflow: geometry baseline, palette coloring, journal templating, and statistical testing with comparison bars.

1.3.1 Step 1: The Basic Geometry

A single formula call renders the unadorned baseline geometry using default styling:

Code 
p_step1 <- cliplot(
  IL13_pg_ml ~ Biomarker,
  data = df_cohort,
  type = "violin"
)
p_step1

1.3.2 Step 2: Add Curated Scientific Color

Applying a publication palette (palette = "nature") assigns coordinated categorical hues across experimental cohorts:

Code 
p_step2 <- cliplot(
  IL13_pg_ml ~ Biomarker,
  data    = df_cohort,
  type    = "violin",
  palette = "nature"
)
p_step2

1.3.3 Step 3: Add Journal Template and Typography

Applying a journal template (theme = "nature") configures open axes, tick direction, typography, panel titles, and axis labels:

Code 
p_step3 <- cliplot(
  IL13_pg_ml ~ Biomarker,
  data     = df_cohort,
  type     = type_violin(inner = "quartiles", quantiles = c(0.25, 0.5, 0.75)),
  palette  = "nature",
  theme    = "nature",
  title    = "Serum IL-13 by Clinical Severity Tier",
  subtitle = "Nature template with interior quartile contours (25%, median, 75%)",
  ylab     = "Serum IL-13 (pg/mL)",
  xlab     = "Biomarker Severity Tier"
)
p_step3

1.3.4 Step 4: Add Statistical Hypothesis Testing with Comparison Bars

Setting stat.test = "wilcox.test" calculates non-parametric rank-sum statistics and draws comparison bracket bars across cohorts:

Code 
p_step4 <- cliplot(
  IL13_pg_ml ~ Biomarker,
  data      = df_cohort,
  type      = type_violin(inner = "boxplot", add_jitter = TRUE, jitter_alpha = 0.35),
  palette   = "nature",
  theme     = "nature",
  stat.test = "wilcox.test",
  title     = "Serum IL-13 Across Clinical Severity Stages",
  subtitle  = "Pairwise Wilcoxon rank-sum test with comparison bracket bars",
  ylab      = "Serum IL-13 (pg/mL)",
  xlab      = "Biomarker Severity Tier"
)
p_step4

1.4 Advanced Distribution Architectures: Split Violins and Rainclouds

cliomicplot provides specialized distribution types for multi-arm clinical trials and single-cell cohorts.

1.4.1 Dual-Condition Contrast: type_split_violin()

When comparing two treatment arms (Placebo vs. Biologic) across multiple severity tiers, type_split_violin() renders both distributions back-to-back along a shared category spine. Each condition is highlighted by group color, with inner boxplots dodged inside each split half. Adding stat.test = "t.test" performs within-tier comparisons with horizontal bracket bars:

Code 
p_split <- cliplot(
  IL13_pg_ml ~ Biomarker | Treatment,
  data      = df_cohort,
  type      = type_split_violin(
    inner     = "boxplot",
    scale     = "width"
  ),
  palette   = "jco",
  theme     = "scifig",
  stat.test = "t.test",
  title     = "IL-13 Modulation Under Biologic vs. Placebo Across Severity Tiers",
  subtitle  = "Split-half comparison with within-tier two-sample t-test",
  ylab      = "Serum IL-13 (pg/mL)",
  xlab      = "Biomarker Severity Tier"
)
p_split

1.4.2 Mean Diamond Glyphs with Standard Error: inner = "mean_se"

Setting inner = "mean_se" replaces median boxplots with an arithmetic mean diamond and standard error errorbars:

Code 
p_mean_stat <- cliplot(
  IL13_pg_ml ~ Treatment,
  data      = df_cohort,
  by        = "Treatment",
  type      = type_violin(
    inner        = "mean_se",
    add_jitter   = TRUE,
    jitter_width = 0.12,
    jitter_alpha = 0.40,
    jitter_size  = 1.6
  ),
  palette   = "cell",
  legend    = "none",
  stat.test = "wilcox.test",
  title     = "Biologic Efficacy on Circulating IL-13",
  subtitle  = "Violin density with raw observations, mean ± SEM diamond, and Wilcoxon test",
  ylab      = "Serum IL-13 (pg/mL)"
)
p_mean_stat

1.5 The Parameter Object: clipar()

clipar() sets visual attributes including line widths, point sizes, alpha transparency, jitter jitter-width, and label font sizes:

Code 
pars <- clipar(
  point_size  = 2.2,
  line_width  = 0.9,
  alpha       = 0.75,
  font_size   = 10
)

p_custom <- cliplot(
  IL13_pg_ml ~ Biomarker,
  data   = df_cohort,
  type   = "beeswarm",
  params = pars,
  preset = "science"
)
p_custom

1.6 Plot Composition and Layer Addition

cliplot() objects are ggplot2 instances. You can extend them using the standard + operator or the cliplot_add() helper:

Code 
p_final <- p_box +
  geom_hline(yintercept = 10, linetype = "dashed", color = "#B22222", linewidth = 0.6) +
  annotate("text", x = 1.2, y = 10.8, label = "Diagnostic Threshold (10 pg/mL)",
           size = 2.8, color = "#B22222", fontface = "bold")
p_final

`cliplot()` provides a single entry point for generating biomedical visualizations through a formula syntax. This chapter details the formula grammar, the parameter system (`clipar`), and the type dispatch architecture.
